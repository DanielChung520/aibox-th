# Sales 模組 nl_examples 設計方案

## 設計原則

1. **場景驅動**：每個 nl_example 都是真實使用場景，不是泛泛的「查詢XX表」
2. **欄位相關**：範例要基於該表實際有的欄位設計
3. **語意差異**：避免多個表有相同的 nl_examples，導致 cosine ≈ 1.0
4. **動作明確**：每個範例包含「動作詞」+「篩選條件」+「目標」

## nl_examples 格式

```json
{
  "nl_examples": [
    "動作詞 + 條件",
    "統計/聚合 + 維度",
    "找出 + 特定條件"
  ]
}
```
