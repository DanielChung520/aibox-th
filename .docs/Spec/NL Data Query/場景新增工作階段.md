# da_intents 場景新增工作階段

## 目標

為每個 domain table 設計具體的 `nl_examples`（場景範例），提升意圖匹配的準確率。

## 設計原則

1. **場景驅動**：每個 nl_example 都是真實使用場景，不是泛泛的「查詢XX表」
2. **欄位相關**：範例要基於該表實際有的欄位設計
3. **語意差異**：避免多個表有相同的 nl_examples
4. **動作明確**：每個範例包含「動作詞」+「維度」+「條件」

## nl_examples 格式範例

```json
{
  "nl_examples": [
    "動作詞 + 條件",
    "統計/聚合 + 維度",
    "找出 + 特定條件",
    "列出 + 排序需求"
  ]
}
```

### Core Table（4 個場景）
- 簡單查詢（1 個）
- 聚合統計（1 個）
- 條件篩選（1 個）
- 排序列表（1 個）

### Basic Table（2 個場景）
- 簡單查詢（1 個）
- 列表查詢（1 個）
