# 通信工具智能體技術研究報告

## 研究背景

本研究旨在分析LINE、WhatsApp、WeCom(企業微信)、DingTalk(釘釘)四大通信平台的Bot接入能力，為AIBox通信工具智能體系統提供技術基礎。研究重點包括：認證與加解密機制、非同步Webhook處理模式、統一訊息格式化、媒體處理能力。

---

## 1. 平台身份識別與接入方式

### 平台特性對照表

| 平台 | 身份識別單位 | 接入方式 | Webhook特性 | 關鍵優勢/限制 |
|------|------------|---------|------------|-------------|
| **LINE** | Channel ID | Messaging API | 5秒內須回傳200 OK | Rich Menu互動性最強，適合台灣市場B2C |
| **WhatsApp** | Phone Number ID | Cloud API (Meta) | 10秒內須回傳200 OK | 檔案傳輸（PDF/Excel）最穩，全球通用性最高 |
| **WeCom** | AgentID (自建應用) | 企業微信 API | 需驗證URL有效性 | 支援企微群機器人與自建代號，適合內部ERP流程 |
| **DingTalk** | AppKey / RobotCode | 釘釘開放平台 | 支持Outgoing模式 | 審批流、工作通知整合度最高，適合複雜OA整合 |

### 多Bot支援能力

| 平台 | 原生多Bot支援 | 限制與解決方案 |
|------|-------------|---------------|
| **LINE** | ❌ 不支援 | 1個LINE OA = 1個Channel，無法設定多個Webhook或sub-bot。可透過第三方Webhook Forwarding服務實作多Bot路由 |
| **WhatsApp** | ⚠️ 有限支援 | 1個WABA可有多個電話號碼（最多25個），但每個App只有1個Webhook URL。多Bot需在應用層自行實作路由 |
| **WeCom** | ✅ 支援 | 每個AI Bot有獨立BotID，支援多帳號配置，每個Bot可建立獨立WebSocket連線 |
| **DingTalk** | ✅ 支援 | 每個企業內部應用 = 1個Bot，可建立多個應用取得多個Bot。Stream Mode (WebSocket)可同時維護多個連線 |

## 2. 認證與加解密機制

### 機制分類

| 平台 | 加密 | 簽名算法 | 複雜度 | 訊息內容 |
|------|------|----------|--------|----------|
| WeCom | ✅ AES-256-CBC | SHA1 | 極高 | 加密 |
| DingTalk | ✅ AES-256-CBC | SHA1 | 極高 | 加密 |
| LINE | ❌ | HMAC-SHA256 | 低 | 明文 |
| WhatsApp | ❌ | HMAC-SHA256 | 低 | 明文 |

### WeCom / DingTalk - AES加解密實作

**加密算法**：AES-256-CBC（PKCS#7填充）  
**簽名算法**：SHA1  
**密鑰**：EncodingAESKey（43字符Base64編碼）  
**IV**：AESKey前16字節

```python
import base64
import hashlib
import struct
from Crypto.Cipher import AES

class WXBizMsgCrypt:
    """企業微信訊息加解密類"""
    
    def __init__(self, token: str, encoding_aes_key: str, corp_id: str):
        self.token = token
        self.corp_id = corp_id
        self.key = base64.b64decode(encoding_aes_key + "=")
    
    def decrypt_msg(self, post_data: str, msg_signature: str, 
                    timestamp: str, nonce: str) -> str:
        """解密接收到的訊息"""
        import xml.etree.ElementTree as ET
        root = ET.fromstring(post_data)
        encrypt = root.find("Encrypt").text
        
        # 驗證簽名
        dev_signature = self._get_sha1(self.token, timestamp, nonce, encrypt)
        if dev_signature != msg_signature:
            raise ValueError("簽名驗證失敗")
        
        return self._decrypt(encrypt)
    
    def _decrypt(self, encrypt: str) -> str:
        """AES解密"""
        cipher_text = base64.b64decode(encrypt)
        iv = self.key[:16]
        cipher = AES.new(self.key, AES.MODE_CBC, iv)
        plain_text = cipher.decrypt(cipher_text)
        
        # 去除PKCS7填充
        pad = plain_text[-1]
        plain_text = plain_text[:-pad]
        
        # 解析結構：random(16B) + msg_len(4B) + msg + corp_id
        msg_len = struct.unpack("!I", plain_text[16:20])[0]
        msg = plain_text[20:20+msg_len].decode('utf-8')
        recv_corp_id = plain_text[20+msg_len:].decode('utf-8')
        
        if recv_corp_id != self.corp_id:
            raise ValueError("CorpID不匹配")
        
        return msg
```

### LINE / WhatsApp - HMAC-SHA256驗證

```python
import hmac
import hashlib
import base64

class LINEWebhookValidator:
    """LINE Webhook驗證器"""
    
    def __init__(self, channel_secret: str):
        self.channel_secret = channel_secret.encode('utf-8')
    
    def validate(self, body: str, signature: str) -> bool:
        """驗證Webhook簽名"""
        hash_digest = hmac.new(
            self.channel_secret,
            body.encode('utf-8'),
            hashlib.sha256
        ).digest()
        
        expected_signature = base64.b64encode(hash_digest).decode('utf-8')
        return hmac.compare_digest(signature, expected_signature)

class WhatsAppWebhookValidator:
    """WhatsApp Webhook驗證器"""
    
    def __init__(self, app_secret: str):
        self.app_secret = app_secret.encode('utf-8')
    
    def validate(self, body: bytes, signature_header: str) -> bool:
        """驗證Webhook簽名"""
        if not signature_header or not signature_header.startswith('sha256='):
            return False
        
        received_signature = signature_header[7:]
        expected_signature = hmac.new(
            self.app_secret,
            body,
            hashlib.sha256
        ).hexdigest()
        
        return hmac.compare_digest(received_signature, expected_signature)
```

### 統一驗證框架

```python
from abc import ABC, abstractmethod

class WebhookValidator(ABC):
    """Webhook驗證器抽象基類"""
    
    @abstractmethod
    def validate(self, body: bytes, headers: dict) -> bool:
        pass

class HMACValidator(WebhookValidator):
    """HMAC-SHA256驗證器（LINE、WhatsApp通用）"""
    
    def __init__(self, secret: str, header_name: str, prefix: str = ''):
        self.secret = secret.encode('utf-8')
        self.header_name = header_name
        self.prefix = prefix
    
    def validate(self, body: bytes, headers: dict) -> bool:
        signature = headers.get(self.header_name, '')
        if self.prefix:
            signature = signature.replace(self.prefix, '', 1)
        
        expected = hmac.new(self.secret, body, hashlib.sha256).hexdigest()
        return hmac.compare_digest(signature, expected)

class AESValidator(WebhookValidator):
    """AES + SHA1驗證器（WeCom、DingTalk通用）"""
    
    def __init__(self, token: str, aes_key: str, receiver_id: str):
        self.token = token
        self.aes_key = aes_key
        self.receiver_id = receiver_id
    
    def validate(self, body: bytes, headers: dict) -> bool:
        # 實作WeCom/DingTalk驗證邏輯
        pass
```

## 3. 非同步Webhook處理模式

### 架構概覽

```
Provider (LINE 5秒/WhatsApp 10秒超時)
    ↓
Webhook接收 → 驗證簽名 → 寫入Redis Queue → 回傳200 OK (<50ms)
    ↓
Background Worker ← Redis Queue (BullMQ)
    ↓
LLM推論 (30-60秒)
    ↓
Push Message API 回覆用戶
```

### Provider超時規則

| Provider | Timeout | Retry Behavior | Best Practice |
|----------|---------|----------------|---------------|
| **LINE** | 1秒 (hard) | 無自動重試 | 500ms內回傳200 |
| **WhatsApp Cloud API** | 3秒 | 3次重試，1分鐘間隔 | 1秒內回傳200 |
| **WeCom** | 視実装 | 無自動重試 | 快速回應 |
| **DingTalk** | 視実装 | 無自動重試 | 快速回應 |

### 快速ACK實作

```python

    """快速Webhook處理 - 50ms內回傳200"""

    signature = request.headers.get('X-Line-Signature')
    body = await request.body()
    
    if not verify_signature(body, signature, WEBHOOK_SECRET):
        raise HTTPException(401, "Invalid signature")
    
    # 2. 解析 payload
    data = await request.json()
    event = {
        'provider': 'line',
        'event_id': data['events'][0]['message']['id'],
        'reply_token': data['events'][0]['replyToken'],
        'user_id': data['events'][0]['source']['userId'],
        'message': data['events'][0]['message']['text'],
        'received_at': int(time.time() * 1000)
    }
    
    # 3. 加入佇列（非阻塞）
    task_queue.enqueue(
        'workers.process_ai_message',
        event,

        job_timeout='120s',
        result_ttl=86400
    )
    
    # 4. 立即回傳（總時間：~30-50ms）
    return {'status': 'queued', 'event_id': event['event_id']}
```

### LINE Reply API vs Push API

| Feature | Reply API | Push API |
|---------|-----------|----------|
| **何時使用** | Webhook接收後30秒內 | 非同步處理（任何時間） |
| **Token** | 一次性replyToken | 長期userId |
| **費用** | **免費**（不計入配額） | **收費**（計入月配額） |
| **配額** | 無限制 | 500/月（免費版）、30,000/月（標準版） |
| **超時** | 30秒內必須使用 | 無超時 |

**建議策略**：AI推論時間通常超過30秒，因此採用「Webhook立即回200 → 背景處理 → Push API回覆」模式。

### Redis Queue去重策略

```python
import redis
import hashlib
import json

r = redis.Redis(host='localhost', port=6379, decode_responses=True)
DEDUP_WINDOW = 86400  # 24小時

def enqueue_if_new(queue: str, payload: dict, message_id: str = None) -> bool:
    """僅在新訊息時加入佇列"""
    
    if message_id is None:
        message_id = hashlib.sha256(
            json.dumps(payload, sort_keys=True).encode()
        ).hexdigest()[:16]
    
    dedup_key = f"dedup:seen:{queue}:{message_id}"
    
    # SET NX EX: 不存在才設定，附帶TTL
    is_new = r.set(dedup_key, "1", nx=True, ex=DEDUP_WINDOW)
    
    if is_new:
        r.rpush(queue, json.dumps({
            'id': message_id,
            'data': payload,
            'queued_at': time.time()
        }))
        return True
    else:
        print(f"Duplicate message {message_id} ignored")
        return False
```

### 平台適配器架構

```python
from abc import ABC, abstractmethod
from dataclasses import dataclass
from typing import Dict, Any, Optional

class Platform(Enum):
    LINE = "line"
    WHATSAPP = "whatsapp"
    WECOM = "wecom"
    DINGTALK = "dingtalk"

@dataclass
class UnifiedMessage:
    id: str
    type: str
    channel: str
    sender: Dict[str, str]
    recipient: Optional[Dict[str, str]]
    content: Dict[str, Any]
    timestamp: str
    thread_id: Optional[str] = None

class PlatformAdapter(ABC):
    """平台適配器抽象介面"""
    
    @abstractmethod
    def to_platform(self, unified_msg: UnifiedMessage) -> Dict[str, Any]:
        """將統一訊息轉換為平台特定格式"""
        pass
    
    @abstractmethod
    def from_platform(self, platform_msg: Dict[str, Any]) -> UnifiedMessage:
        """將平台訊息轉換為統一格式"""
        pass
    
    @abstractmethod
    def supports_feature(self, feature: str) -> bool:
        """檢查平台是否支援特定功能"""
        pass
    
    def get_fallback(self, unified_msg: UnifiedMessage) -> Dict[str, Any]:
        """針對不支援功能的降級處理"""
        return {"type": "text", "text": unified_msg.content.get("text", "")}
```

### 降級策略

```python
class FeatureFallbackStrategy:
    """針對不支援功能的降級策略"""
    
    @staticmethod
    def degrade_interactive_message(unified_msg: UnifiedMessage, platform: Platform) -> Dict[str, Any]:
        """
        降級鏈：
        1. 嘗試原生互動（按鈕/列表）
        2. 降級為快速回覆（LINE支援）
        3. 降級為純文字編號選項
        """
        
        adapter = adapter_manager.get_adapter(platform)
        content = unified_msg.content
        
        # Level 1: 完全支援
        if adapter.supports_feature("interactive_buttons"):
            return adapter.to_platform(unified_msg)
        
        # Level 2: 快速回覆支援
        elif adapter.supports_feature("quick_reply"):
            return {"type": "text", "text": content["body"]}  # 簡化實作
        
        # Level 3: 純文字編號
        else:
            text = content["body"] + "\n\nReply with a number:\n"
            for idx, item in enumerate(content["action"]["items"], 1):
                text += f"{idx}. {item['title']}\n"
            return {"type": "text", "text": text}
```

### Redis快取策略

```python
import hashlib
from datetime import datetime, timedelta
import redis

class MediaCache:
    def __init__(self):
        self.redis = redis.Redis(host='localhost', port=6379, db=0)
    
    def should_reupload(self, cache_entry: dict, platform: str) -> bool:
        """判斷是否需要重新上傳"""
        if not cache_entry:
            return True
        
        now = datetime.utcnow()
        
        if platform == "whatsapp":
            # 過期前1天重新上傳
            return now >= cache_entry['expires_at'] - timedelta(days=1)
        
        elif platform == "wecom":
            # 過期前6小時重新上傳
            return now >= cache_entry['expires_at'] - timedelta(hours=6)
        
        elif platform == "dingtalk":
            # DingTalk永久有效，永遠複用
            return False
        
        return True
    
    def cache_media(self, file_path: str, platform: str, media_id: str, ttl_days: int):
        """快取已上傳的media_id"""
        file_hash = self._get_file_hash(file_path)
        key = f"{platform}:media:{file_hash}"
        
        entry = {
            "media_id": media_id,
            "upload_date": datetime.utcnow().isoformat(),
            "expires_at": (datetime.utcnow() + timedelta(days=ttl_days)).isoformat()
        }
        
        # Redis TTL略長於過期時間
        self.redis.setex(key, timedelta(days=ttl_days+1), json.dumps(entry))
```

### WhatsApp媒體上傳範例

```python
import requests
from pathlib import Path

class WhatsAppMediaManager:
    def __init__(self, phone_number_id: str, access_token: str, redis_client=None):
        self.phone_number_id = phone_number_id
        self.access_token = access_token
        self.base_url = "https://graph.facebook.com/v18.0"
        self.cache = redis_client
    
    def upload_media(self, file_path: str, mime_type: str) -> str:
        """上傳媒體並返回media_id（含快取）"""
        
        # 檢查快取
        if self.cache:
            cached_id = self._get_cached_media(file_path)
            if cached_id:
                return cached_id
        
        # 上傳新媒體
        url = f"{self.base_url}/{self.phone_number_id}/media"
        headers = {"Authorization": f"Bearer {self.access_token}"}
        
        with open(file_path, 'rb') as f:
            files = {
                'file': (Path(file_path).name, f, mime_type),
                'messaging_product': (None, 'whatsapp'),
                'type': (None, mime_type)
            }
            response = requests.post(url, headers=headers, files=files, timeout=60)
            response.raise_for_status()
        
        media_id = response.json()['id']
        
        # 快取30天
        if self.cache:
            self._cache_media(file_path, media_id, ttl_days=30)
        
        return media_id
    
    def send_document(self, to_number: str, media_id: str, filename: str, caption: str = None):
        """使用media_id發送文件"""
        url = f"{self.base_url}/{self.phone_number_id}/messages"
        headers = {
            "Authorization": f"Bearer {self.access_token}",
            "Content-Type": "application/json"
        }
        
        payload = {
            "messaging_product": "whatsapp",
            "to": to_number,
            "type": "document",
            "document": {
                "id": media_id,
                "filename": filename
            }
        }
        
        if caption:
            payload["document"]["caption"] = caption
        
        response = requests.post(url, headers=headers, json=payload, timeout=30)
        response.raise_for_status()
        return response.json()['messages'][0]['id']
```
