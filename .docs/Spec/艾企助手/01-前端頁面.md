# 01 — 前端頁面

> 艾企助手的前端元件架構、UI 互動行為、渲染規則

---

## 1. 元件架構

```
App.tsx
└── <FloatingAssistant />          # index.tsx — 主元件（全域掛載）
    ├── <ChatModal />              # ChatModal.tsx — 聊天窗口
    │   ├── <MermaidBlock />       # 內嵌子元件 — Mermaid 圖表渲染
    │   └── <MarkdownContent />    # 內嵌子元件 — Markdown 渲染
    └── <FloatingButton />         # FloatingButton.tsx — 浮動按鈕
```

**掛載位置**：`App.tsx` 的 `<BrowserRouter>` 內、`<Routes>` 同層，確保可存取 React Router 的 `useLocation`。

## 2. 浮動按鈕 (FloatingButton)

### 2.1 基本規格

| 屬性 | 值 |
|------|------|
| 尺寸 | 56×56 px |
| 形狀 | 圓形 (`border-radius: 50%`) |
| 預設位置 | 右下角，距邊緣 20px |
| z-index | 9999 |
| 動畫 | 3 秒循環脈衝 (`floating-pulse`) |

### 2.2 顯示邏輯

| 條件 | 顯示內容 |
|------|---------|
| `avatarSrc` 存在 | 圓形頭像 `<img>` |
| `avatarSrc` 為空 | `<RobotOutlined />` 圖標 |

### 2.3 互動行為

| 操作 | 行為 |
|------|------|
| 點擊 | 切換聊天窗開關 (`handleToggle`) |
| 拖拽 | 自由拖拽至螢幕任意位置 |
| 按住 | `cursor: grabbing`，停止脈衝動畫 |
| 懸停 | 增強陰影 (`box-shadow` 加深) |
| 視窗縮放 | 自動調整位置，防止跑出螢幕 |

### 2.4 容器配置

```css
.floating-assistant-container {
  position: fixed;
  z-index: 9999;
  top: 0;
  left: 0;
  width: 0;      /* 不佔據空間 */
  height: 0;
  overflow: visible;  /* 子元素可溢出 */
}
```

> **重要**：容器使用 `width: 0; height: 0; overflow: visible` 而非 `100vw/100vh`，避免覆蓋整個畫面攔截滑鼠事件。

## 3. 聊天窗口 (ChatModal)

### 3.1 基本規格

| 屬性 | 預設值 | 可配置 |
|------|--------|--------|
| 寬度 | 480px | ✅ `modalWidth` |
| 高度 | 600px | ✅ `modalHeight` |
| 最小寬度 | 280px | 否（硬編碼） |
| 最小高度 | 300px | 否（硬編碼） |
| 邊框圓角 | 12px | ✅ `borderRadius` |
| 開啟動畫 | `transform-origin` 從按鈕位置展開 | 否 |

### 3.2 視覺風格 — Glassmorphism

聊天窗使用毛玻璃（glassmorphism）設計，所有顏色透過 CSS Variables 驅動：

| 區域 | CSS Variable | 預設值 |
|------|-------------|--------|
| 整體背景 | `--fa-modal-bg` | `rgba(30, 41, 59, 0.85)` |
| Header 背景 | `--fa-header-bg` | `rgba(22, 27, 34, 0.75)` |
| 內容區背景 | `--fa-body-bg` | `rgba(30, 41, 59, 0.6)` |
| Footer 背景 | `--fa-footer-bg` | `rgba(22, 27, 34, 0.75)` |
| 模糊強度 | `--fa-blur-intensity` | `20px` |
| 玻璃透明度 | `--fa-glass-opacity` | `0.65` |
| 飽和度 | `--fa-saturation` | `180%` |

### 3.3 結構佈局

```
┌──────────────────────────────┐
│  Header（可拖拽）              │
│  [頭像] 艾企            [✕]   │
├──────────────────────────────┤
│                              │
│  Body（訊息列表，可捲動）       │
│                              │
│  ┌─ system ─┐               │
│  │ 今天 10:00 │               │
│  └───────────┘               │
│                              │
│  ┌─ assistant ──────────┐    │
│  │ 你好！我是艾企...      │    │
│  │ 📍 您目前在「首頁」    │    │
│  └──────────────────────┘    │
│                              │
├──────────────────────────────┤
│  Suggestions（快捷提問按鈕）    │
│  [如何查看表結構？] [新增欄位？] │
├──────────────────────────────┤
│  Footer                      │
│  [輸入框______________] [發送] │
├──────────────────────────────┤
│                          ◢   │  ← 右下角縮放手柄
└──────────────────────────────┘
```

### 3.4 互動行為

| 操作 | 行為 |
|------|------|
| 拖拽 Header | 移動整個聊天窗，限制不超出螢幕 |
| 拖拽右下角手柄 | 縮放聊天窗，最小 280×300 |
| 輸入框 Enter | 發送訊息 |
| 點擊發送按鈕 | 發送訊息 |
| 點擊關閉 (✕) | 關閉聊天窗（不清除歷史） |
| 點擊快捷按鈕 | 將建議文字填入輸入框 |
| 視窗縮放 | 自動調整位置，防止跑出螢幕 |

### 3.5 開關狀態與 pointer-events

```css
.floating-modal {
  pointer-events: none;     /* 關閉時不攔截點擊 */
  opacity: 0;
  transform: scale(0.3);
}

.floating-modal.open {
  pointer-events: auto;     /* 開啟時才接收點擊 */
  opacity: 1;
  transform: scale(1);
}
```

> **重要**：關閉狀態的 modal 必須 `pointer-events: none`，否則透明的 modal 會攔截下方頁面的所有點擊事件。

## 4. 訊息類型

### 4.1 ChatMessage Interface

```typescript
interface ChatMessage {
  id: string;
  role: 'user' | 'assistant' | 'system';
  content: string;
  timestamp: Date;
}
```

### 4.2 渲染規則

| role | 佈局 | 樣式 |
|------|------|------|
| `system` | 置中 | 小字、低對比度（時間戳、頁面切換提示） |
| `assistant` | 靠左 | AI 氣泡，背景 `--fa-bubble-ai-bg` |
| `user` | 靠右 | 使用者氣泡，背景 `--fa-bubble-user-bg` |

### 4.3 Markdown 渲染

使用 `react-markdown` + `remark-gfm`，支持：

- 粗體、斜體、刪除線
- 程式碼區塊（syntax highlighting 待定）
- 表格
- 連結
- 有序/無序列表
- 引用區塊

### 4.4 Mermaid 圖表

使用獨立 `<MermaidBlock>` 子元件渲染，避免違反 React Rules of Hooks：

```typescript
function MermaidBlock({ code }: { code: string }) {
  // useEffect 呼叫 mermaid.render() 取得 SVG
  // 成功 → dangerouslySetInnerHTML 渲染 SVG
  // 失敗 → 顯示錯誤訊息
}
```

支持的 Mermaid 圖表類型：`graph`、`flowchart`、`sequenceDiagram`、`classDiagram`、`gantt` 等。

## 5. 快捷提問按鈕 (Suggestions)

### 5.1 位置

在 Body 與 Footer 之間，獨立的 `.floating-modal-suggestions` 區域。

### 5.2 渲染規則

- 根據當前 `pageContext.suggestions` 陣列動態渲染
- 每個建議為一個 `<button>` 膠囊按鈕
- `flex-wrap: wrap` 佈局，自動換行
- 點擊後將文字填入輸入框（不自動發送）

### 5.3 樣式

```css
.floating-suggestion-btn {
  padding: 4px 10px;
  font-size: 12px;
  border: 1px solid var(--fa-input-border-color);
  border-radius: 12px;
  background: var(--fa-input-bg);
  color: var(--fa-bubble-ai-text-color);
}

.floating-suggestion-btn:hover {
  background: var(--fa-send-btn-bg);
  border-color: var(--fa-send-btn-bg);
  color: var(--fa-send-btn-color);
}
```

## 6. 頭像顯示

### 6.1 資料來源

- 圖片存放於 `src/assets/avatar/*.png`（21 張 1024×1024 動漫風格）
- 使用者透過系統參數頁面選擇頭像，值存入 DB `basic.avatar`（頭像名稱，不含副檔名）
- 透過 `import.meta.glob` eager 載入所有頭像模組

### 6.2 顯示位置

| 位置 | 有頭像時 | 無頭像時 |
|------|---------|---------|
| 浮動按鈕 | 圓形 `<img>` | `<RobotOutlined />` |
| 聊天窗 Header | `<Avatar src>` | `<Avatar icon={<RobotOutlined />}>` |
| 頁面 Header | `<Avatar src>` | `<Avatar icon={<RobotOutlined />}>` |

### 6.3 即時同步

頭像變更透過 `CustomEvent('avatar-changed')` 即時同步到所有顯示位置，無需重新載入。
