### 1.3 儲存機制

- 每個配置項對應一筆 `system_params` 記錄
- Key 格式：`floating_assistant.{configKey}`
- 值統一以 `string` 型態存入 DB
- 保存時逐項呼叫 `paramsApi.update(key, value)`
- 保存成功後 dispatch `CustomEvent('floating-assistant-config-update')`

### 1.4 ColorPicker 注意事項

Ant Design 6.x 的 `ColorPicker` 元件在 `Form.getFieldsValue()` 回傳 `Color` 物件（非字串），必須用 `toRgbString()` 轉換：

```typescript
const isColorValue = (value: unknown): value is ColorValueLike =>
  typeof value === 'object' && value !== null && 'toRgbString' in value;

const toColorString = (value: unknown, fallback: string): string => {
  if (isColorValue(value)) return value.toRgbString();
  if (typeof value === 'string' && value.trim() !== '') return value;
  return fallback;
};
```

## 2. 頭像設置

### 2.1 入口

系統管理 → 系統參數 → 基本信息（tab）→ 右側頭像設置區域

**對應檔案**：`src/pages/SystemParams.tsx` v1.1.0

### 2.2 資料來源

- 圖片路徑：`src/assets/avatar/*.png`
- 載入方式：`import.meta.glob('../../assets/avatar/*.png', { eager: true })`
- 圖片數量：21 張
- 圖片尺寸：1024×1024 px
- 圖片風格：動漫風格角色

### 2.3 選擇器 UI

- Grid 佈局，每行 4 張
- 選中狀態：`border: 2px solid primaryColor` + 勾選圖標
- 點擊即保存至 DB

### 2.4 DB 儲存

| 屬性 | 值 |
|------|------|
| Key | `basic.avatar` |
| Value | 頭像檔名（不含 `.png` 副檔名） |
| API | `paramsApi.update('basic.avatar', avatarName)` |
| 讀取 | `paramsApi.get('basic.avatar')` |

### 2.5 即時同步機制

```
選擇頭像 → DB 保存 → dispatch CustomEvent('avatar-changed', { detail: { name } })
                                    ↓
                    ┌───────────────┼───────────────┐
                    ↓               ↓               ↓
              HeaderControls   FloatingButton   ChatModal Header
              (頁面 Header)     (浮動按鈕)       (聊天窗標題)
```

所有監聽點使用 `window.addEventListener('avatar-changed', handler)` 接收，並在 `useEffect` cleanup 時移除。

## 3. 啟停控制

### 3.1 機制

`FloatingAssistantConfig.enabled` 為 `false` 時，`FloatingAssistant` 元件直接回傳 `null`：

```typescript
if (config.enabled === false) {
  return null;
}
```

### 3.2 設定方式

在浮動助手設置頁面中的 `<Switch>` 元件控制，保存至 DB `floating_assistant.enabled`。

## 4. 即時同步事件清單

| 事件名稱 | 觸發時機 | Payload | 消費者 |
|---------|---------|---------|--------|
| `floating-assistant-config-update` | 設置頁面保存配置 | `FloatingAssistantConfig` | `index.tsx`, `ChatModal.tsx` |
| `avatar-changed` | 系統參數頁面選擇頭像 | `{ name: string }` | `index.tsx`, `HeaderControls.tsx` |

## 5. 配置載入流程

```
應用啟動
  ↓
FloatingAssistant mount
  ↓
paramsApi.list() 載入所有 system_params
  ↓
過濾 floating_assistant.* 前綴 → 合併至 defaultConfig
  ↓
applyStylesToCss() → 設定 38+ 個 CSS Variables 到 document.documentElement
  ↓
同時 paramsApi.get('basic.avatar') → 解析頭像 → setAvatarSrc
  ↓
監聽 CustomEvent 等待後續即時更新
```
