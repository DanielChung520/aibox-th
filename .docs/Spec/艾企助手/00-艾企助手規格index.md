# 艾企助手功能規格書 — 索引與閱讀指南

> **版本**: 1.1.0
> **狀態**: 初版
> **範疇**: 前端浮動助手 + 頁面感知 + AI 對話 + 後台配置
> **目標讀者**: AI Coder Agent（用於實作開發）

---

## TL;DR

「艾企」是 AIBox 的全域浮動 AI 助手，常駐於應用右下角，提供：

- **即時對話**：使用者可隨時與 AI 對話，支持 Markdown 和 Mermaid 圖表渲染
- **頁面感知**：自動辨識使用者所在功能頁面，提供情境化的引導與快捷提問
- **可自訂外觀**：透過系統參數頁面調整 38+ 項 CSS 樣式配置，包含頭像設置
- **未來擴展**：支持 RAG 知識庫驅動的動態建議、頁面深度上下文、跨頁導航

**名稱由來**：「艾企」= AI + 企業，「您的 AI 企業好助手」

## 術語對照

| 術語 | 說明 |
|------|------|
| 艾企 | 浮動 AI 助手的品牌名稱（AI + 企業） |
| FloatingAssistant | 艾企的前端元件名稱 |
| PageContext | 頁面感知上下文物件 `{ name, description, suggestions }` |
| PAGE_CONTEXT_MAP | 路由 → PageContext 的靜態對照表 |
| FloatingAssistantConfig | 38+ 項樣式配置的 TypeScript interface |
| system_params | ArangoDB 中的系統參數集合，用於持久化配置 |
| CustomEvent | 瀏覽器原生事件，用於跨元件即時通訊 |
| glassmorphism | 毛玻璃（磨砂玻璃）UI 設計風格 |
| Action Trail | 操作軌跡，記錄使用者在頁面內的操作序列（方案 D） |
| 頁面 Ontology | 頁面能力描述，定義每個頁面的 entities、capabilities、skills |
| Intent Inference | 意圖推斷引擎，根據 Action Trail + Ontology 推測使用者意圖 |
| 延伸分析 | 表格 UI 能力缺口的補充：聚合統計、跨表 JOIN、趨勢分析等 |
