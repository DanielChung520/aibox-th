# 市場觀察助手規格（Market Intel）

## 1. 概述

自動化市場資訊蒐集與分析工具。每日透過 DuckDuckGo 搜尋關鍵字，抓取網頁內容，經 LLM 摘要分析後產出產業快報，包含趨勢、注意事項、商機建議。

## 2. 系統架構

```
業務點擊「重新整理」
    │
    ▼
前端 POST /api/v1/market-intel/refresh-celery
    │
    ▼
Rust API Gateway proxy → unified_agents (8011)
    │
    ▼
Celery 背景任務 market_intel_refresh
    │
    ├── 1. DuckDuckGo HTML 搜尋（關鍵字）
    │      └── 去年 Google News RSS（JS 跳轉無法取得內容）
    │
    ├── 2. fetch_page_content() 抓取文章內文
    │
    ├── 3. LLM summarize_article() 單篇摘要
    │      └── deepseek-v4-flash via OpenCode Go
    │      └── max_tokens: 2000
    │      └── _try_parse_json() 容錯解析
    │
    ├── 4. LLM generate_daily_report() 整合分析
    │      └── 產出 daily_focus + key_trends + attention_points + opportunities + overall_assessment
    │
    └── 5. 寫入 ArangoDB market_intel_reports（含 created_by）
```

## 3. 權限模型

| 角色 | 可重新整理 | 可修改個人設定 | 可管理權限 | 可設定保留天數 |
|:----:|:--------:|:------------:|:--------:|:------------:|
| 業務主管 | ✅ | ✅ | ✅ | ✅ |
| 系統管理員 | ✅ | ✅ | ✅ | ✅ |
| 業務員（可更新） | ✅ | ✅ | ❌ | ❌ |
| 業務員（唯讀） | ❌ | ❌ | ❌ | ❌ |

## 4. 前端頁面

### 📋 今日快報（DailyBrief）

| 區塊 | 說明 |
|------|------|
| 標題列 | daily_focus + 重新整理按鈕（依權限顯示） |
| 總摘要 | overall_assessment（min-height 60px，超出可滾動） |
| 三欄卡片 | 📈 趨勢 / ⚠️ 注意 / 💡 商機（max-height 160px） |
| Tab 切換 | 🔴 高關聯 / 🟡 中關聯 / ℹ️ 一般資訊（max-height 420px 可滾動） |
| Token 統計 | 本次 LLM 用量 |
| 主管合併 | 可更新權限的業務員可看到主管的 items 附加 [管] 標籤 |

### 📅 執行記錄（HistoryTab）

| 功能 | 說明 |
|------|------|
| 記錄列表 | 每筆顯示日期、摘要、篇數、token、建立時間 |
| 懸浮效果 | 深淺主題自適應背景色 |
| 搜尋欄 | 依日期或摘要關鍵字過濾 |
| 多選刪除 | checkbox + 全選 + 批次刪除 |
| 點擊查看 | 開啟 Modal 顯示該次完整快報內容 |

### ⚙️ 操作設置（SettingsTab）

| 功能 | 可見角色 |
|------|:-------:|
| 👥 權限管理（業務員列表 + 讀/更新權限） | 業務主管、系統管理員 |
| 🗑️ 快報保留設定（保留天數，預設 10 天） | 業務主管、系統管理員 |
| 🎯 關注領域 ／ 🔑 關鍵詞 ／ ⏰ 推播設定 | 業務主管、系統管理員、可更新業務員 |

## 5. 後端端點

| 方法 | 路徑 | 說明 |
|:----:|------|------|
| GET | /api/v1/market-intel/latest | 最新快報（可指定 user_key） |
| GET | /api/v1/market-intel/history | 歷史記錄（可指定 user_key） |
| GET | /api/v1/market-intel/report-by-key/{key} | 指定版本快報 |
| POST | /api/v1/market-intel/refresh-celery | 觸發 Celery 背景執行 |
| POST | /api/v1/market-intel/delete-reports | 批次刪除 |
| POST | /api/v1/market-intel/cleanup | 清理過期記錄 |
