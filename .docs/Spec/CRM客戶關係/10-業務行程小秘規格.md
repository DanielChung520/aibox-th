# 業務行程小秘規格（Visit & Expense）

## 1. 概述

業務外出行程管理與費用報銷工具。支援行程 CRUD、地圖估程、提醒通知、報銷單 CRUD 與審核流程。

## 2. 行程管理

### 2.1 資料模型

#### Collection: visit_plans（需新建）

```json
{
  "_key": "uuid",
  "customer_id": "crm_contact_key",
  "customer_name": "陳先生",
  "visit_date": "2026-06-20",
  "visit_time": "10:00",
  "location": "台北市大安區...",
  "lat_lng": [25.034, 121.564],
  "estimated_travel_min": 25,
  "status": "planned | done | cancelled",
  "notes": "",
  "reminder_sent": false,
  "created_by": "user_key",
  "created_at": "ISO datetime",
  "updated_at": "ISO datetime"
}
```

索引：`[customer_id, visit_date]`、`[created_by, status]`

### 2.2 API 端點

| 方法 | 路徑 | 說明 |
|:----:|------|------|
| GET | /api/v1/visits | 行程列表（日期範圍/狀態/業務員） |
| POST | /api/v1/visits | 新增行程 |
| PUT | /api/v1/visits/{key} | 修改行程 |
| DELETE | /api/v1/visits/{key} | 刪除行程 |
| GET | /api/v1/visits/calendar | 行事曆視圖（月/週） |

### 2.3 地圖估程整合

新增行程時可選呼叫 Google Maps Distance Matrix API 估算路程時間，填入 `estimated_travel_min`。

### 2.4 提醒通知

當天早上定時檢查 `visit_plans`，對 `status=planned` 且 `reminder_sent=false` 的行程發送 LINE 通知。

## 3. 費用報銷

### 3.1 資料模型

#### Collection: expense_reports（需新建）

```json
{
  "_key": "uuid",
  "business_user_key": "user_key",
  "visit_id": "visit_key（optional，關聯行程）",
  "expense_date": "2026-06-18",
  "category": "交通 | 餐飲 | 住宿 | 其他",
  "amount": 1500,
  "description": "拜訪客戶計程車費",
  "receipt_url": "SeaweedFS URL（憑證圖片）",
  "status": "draft | submitted | approved | rejected | paid",
  "reviewer_key": "supervisor_key",
  "reviewed_at": "ISO datetime",
  "review_note": "",
  "created_at": "ISO datetime",
  "updated_at": "ISO datetime"
}
```

索引：`[business_user_key, status]`

### 3.2 審核流程

```
draft（草稿） → submitted（送出） → approved（主管核准） → paid（會計付款）
                                        → rejected（駁回 → draft）
```

### 3.3 API 端點

| 方法 | 路徑 | 說明 |
|:----:|------|------|
| GET | /api/v1/expenses | 報銷清單（可依狀態/日期/業務員過濾） |
| POST | /api/v1/expenses | 新增報銷（含憑證上傳 SeaweedFS） |
| PUT | /api/v1/expenses/{key} | 修改報銷 |
| DELETE | /api/v1/expenses/{key} | 刪除報銷 |
| PUT | /api/v1/expenses/{key}/approve | 主管審核（核准/駁回） |
