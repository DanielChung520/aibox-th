## 1. 概述

EEA-CRM 客戶列表為雙源資料（衛福部、商業司）的統一客戶管理介面，提供搜尋、篩選、分類及權限管理功能。資料串接 Rust API Gateway → ArangoDB，已移除 Mock 資料。

### 1.1 技術棧

| 層 | 技術 |
|---|------|
| 前端框架 | React 18 + TypeScript |
| UI 元件庫 | Ant Design 6.x |
| HTTP 客戶端 | Axios |
| 後端 | Rust Axum (port 6500) |
| 資料庫 | ArangoDB |

### 1.2 資料來源

| 來源 | key | 說明 | 筆數 |
|------|-----|------|:----:|
| 衛福部 | `mohw` | 衛生福利部長照機構公開資料 | 15,362 |
| 商業司 | `business_kindom` | 經濟部公司登記資料 | 17,128 |
| **合計** | | | **32,490** |

## 2. 資料模型

### 2.1 CRMCustomer

```typescript
interface CRMCustomer {
  _key: string;
  source: 'mohw' | 'business_kindom';
  status: 'potential' | 'lead' | 'customer' | 'merged';
  name: string;
  name_short?: string;
  name_raw?: string;
  mohw_id?: string;
  business_kindom_id?: string;
  phone?: string;
  email?: string;
  contact_person?: string;
  address?: string;
  city?: string;
  district?: string;
  lat?: number;
  lng?: number;
  abc_grade?: string;         // A/B/C/E
  category?: string[];        // 機構類型（巷弄長照站、喘息服務、居家服務…）
  org_tags?: string[];        // 機構分類標籤
  sales_rep?: string;         // 業務負責人
  tags?: string[];
  last_contact_at?: string;
  last_contact_note?: string;
  merge_status?: string;
  merged_into?: string;
  created_at: string;
  updated_at: string;
  synced_at?: string;
  import_batch?: string;
  _perm_assigned?: boolean;
  _perm_authorized?: boolean;
}
```

### 2.2 狀態 enum

| 值 | 顯示 | 說明 |
|----|------|------|
| `potential` | 潛在客戶 | 衛福部資料（尚未接觸） |
| `lead` | 業務接觸中 | 商業司資料（已建立聯繫管道） |
| `customer` | 既有客戶 | 已成為正式客戶 |
| `merged` | 已合併 | 已被合併至其他記錄 |

### 2.3 ABC/E 分類

| 等級 | 顏色 | 說明 |
|:----:|:----:|------|
| A | 🟢 #52c41a | 高價值客戶 |
| B | 🟡 #faad14 | 中等價值 |
| C | 🔴 #ff4d4f | 一般（衛福部預設） |
| E | 🟣 #b37feb | 外部來源（商業司預設） |

## 3. API

### 3.1 列表查詢

```
GET /api/v1/crm/customers
Authorization: Bearer <token>
```

**Query Parameters:**

| 參數 | 型態 | 說明 |
|------|------|------|
| `page` | number | 頁碼（預設 1） |
| `page_size` | number | 每頁筆數（預設 10） |
| `q` | string | 全文搜尋（機構名稱） |
| `source` | string | 資料來源篩選 |
| `status` | string | 狀態篩選 |
| `abc_grade` | string | ABC/E 分類篩選 |
| `city` | string | 縣市篩選 |

**Response:**

```json
{
  "data": [ CRMCustomer, ... ],
  "pagination": {
    "page": 1,
    "page_size": 10,
    "total": 32490,
    "total_pages": 3249
  },
  "summary": {
    "total": 32490,
    "by_source": { "mohw": 15362, "business_kindom": 17128 },
    "by_status": { "potential": 15362, "lead": 17128 }
  }
}
```

### 3.2 更新客戶

```
PATCH /api/v1/crm/customers/{key}
```

### 3.3 資料匯入

| 方法 | 路徑 | 說明 |
|------|------|------|
| POST | `/api/v1/crm/customers/import/business-kindom` | 匯入商業司資料 |
| POST | `/api/v1/crm/customers/import/mohw` | 觸發衛福部資料更新 |

## 4. 頁面功能

### 4.1 目前實作

| 功能 | 狀態 | 說明 |
|------|:----:|------|
| API 資料串接 | ✅ | Axios → crmApi.list()，server-side pagination |
| 搜尋 | ✅ | 關鍵字搜尋機構名稱 |
| ABC/E 篩選 | ✅ | 下拉選擇 A/B/C/E |
| 區域篩選 | ❌ | 暫未實作 |
| 分頁 | ✅ | Server-side，10 筆/頁 |
| 載入狀態 | ✅ | Spin loading |
| 潛在客戶爬取 Modal | ✅ | 呼叫 import API |
| 新增客戶 | ❌ | message.info 佔位 |
| 匯入 CSV | ❌ | message.info 佔位 |
| 右鍵選單 | ❌ | 暫未實作 |
| 詳情 Drawer | ❌ | 暫未實作（按鈕顯示 message.info） |
| 權限管理 | ❌ | 暫未實作 |

### 4.2 表格欄位

| 欄位 | 對應 API 欄位 | 渲染 |
|------|:------------:|------|
| 機構名稱 | `name` | bold |
| 統一編號 | `business_kindom_id \|\| mohw_id` | 文字 |
| 區域 | `city \|\| district` | 文字 |
| ABC分類 | `abc_grade` | Tag（顏色標示） |
| 業務負責人 | `sales_rep` | 文字 |
| 最近互動 | `last_contact_at` | 文字 |
| 狀態 | `status` | Tag |

### 4.3 搜尋與篩選

- **搜尋欄位**：機構名稱關鍵字（300ms debounce）
- **ABC分類**：A類 / B類 / C類 / E類
- **業務負責人**：由已載入資料動態產生選項

## 5. 機構類型（category）

### 5.1 來源

由 LLM 名稱正規化比對（衛福部 vs 商業司）自動產生：

- 兩邊名稱經 `omlx-server` (Qwen3-VL-8B) 理解正規化
- 正規化名稱相同者視為同一機構
- 商業司記錄繼承衛福部的 `category` 作為機構類型
- 無匹配的商業司記錄設為 `["其他"]`
