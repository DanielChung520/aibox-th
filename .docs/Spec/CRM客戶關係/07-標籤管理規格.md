# 標籤管理規格

## 1. 概述

機構分類標籤管理頁面，允許使用者檢視、新增、編輯、刪除客戶分類標籤。標籤用於客戶列表的機構分類過濾與自動分類。

## 2. 資料模型

### Collection: tags（ArangoDB）

```json
{
  "_key": "uuid",
  "name": "標籤名稱",
  "color": "標籤顏色（hex）",
  "category": "分類群組（optional）",
  "sort_order": 0,
  "created_at": "ISO datetime"
}
```

## 3. API 端點

| 方法 | 路徑 | 說明 |
|:----:|------|------|
| GET | /api/v1/tags | 列出所有標籤 |
| POST | /api/v1/tags | 新增標籤 |
| PUT | /api/v1/tags/{key} | 修改標籤 |
| DELETE | /api/v1/tags/{key} | 刪除標籤 |

## 5. 自動分類邏輯

客戶匯入時自動根據機構名稱關鍵字比對產生 `org_tags`：

- 關鍵字比對 + 分類映射（約 20 種業務王分類）
- 覆蓋率：約 75%（24,511/32,490 筆）
- 可透過右鍵選單手動調整
