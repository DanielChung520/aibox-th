# 業務戰情助手規格（Sales Intel）

## 1. 概述

銷售數據視覺化儀表板，彙整 Ragic ERP 歷史交易資料，提供營收 KPI、區域/產品分析、業務員排名、月度趨勢圖。目標取代人工 Excel 報表。

## 2. 資料來源

| 資料 | Ragic 來源表 | 用途 |
|------|:-----------:|------|
| 營收 KPI | 訂購單 ERP_2、銷貨單 ERP_26 | 當月/累計營收、成長率、目標達成率 |
| 區域分析 | 訂購單（依客戶區域分群） | 北/中/南/東 銷售分布 |
| 產品分析 | 訂購單（依產品分類） | A/B/C/D 類產品銷售佔比 |
| 業務員排名 | 訂購單（依業務員彙總） | 個人業績排行 |
| 月度趨勢 | 銷貨單（依月份彙總） | 12 個月營收走勢 |

## 3. API 端點（全部需新建）

| 方法 | 路徑 | 說明 |
|:----:|------|------|
| GET | /api/v1/sales/kpi | 營收/成長率/達標率/活躍客戶數 |
| GET | /api/v1/sales/regional | 區域別銷售額 |
| GET | /api/v1/sales/product | 產品別銷售分析 |
| GET | /api/v1/sales/ranking | 業務員業績排名 |
| GET | /api/v1/sales/trend | 每月趨勢圖（可指定月數） |

### 資料彙整方式

透過既有的 Ragic Data Agent（ai-services/data_agent/ragic/）查詢 Ragic ERP 表單：

```
Rust API Gateway → /api/v1/ragic/query → unified_agents Data Agent → Ragic API
```

或直接在 Rust 端撰寫彙總邏輯，呼叫 Python 服務進行資料聚合。
