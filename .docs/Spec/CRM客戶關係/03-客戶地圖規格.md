# 客戶地圖規格

## 1. 概述

基於 Leaflet 的地圖視圖，呈現衛福部 + 商業司雙源客戶的空間分布。支援 ABC/E 分級篩選、機構類型篩選、marker cluster 分群、點擊 marker 顯示浮動行動選單、路線規劃、起點/終點設定。

## 2. 資料來源

地圖資料來自 ArangoDB `crm_customers`，經由 Rust API Gateway 提供：

| 來源 | 說明 | 預設 abc_grade |
|------|------|:--------------:|
| 衛福部（mohw） | 長照機構公開資料 | C |
| 商業司（business_kindom） | 公司登記資料 | E |

**Marker 顏色依 ABC/E 分級，非依來源：**

| 分級 | 顏色 | 半徑 | 說明 |
|:----:|:----:|:----:|------|
| A | 🟢 #52c41a | 10px | 高價值 |
| B | 🟡 #faad14 | 8px | 中等 |
| C | 🔴 #ff4d4f | 6px | 一般 |
| E | 🟣 #b37feb | 7px | 外部來源 |

**台灣福祉總部**固定顯示紅色圓點標記於新北市樹林區。

## 3. API 端點

### GET /api/v1/crm/customers/map

Request:
```
bbox?      string  — "sw_lat,sw_lng,ne_lat,ne_lng"
source?    string  — mohw | business_kindom
status?    string  — potential | lead | customer
abc_grade? string  — A | B | C | E
city?      string  — 縣市
```

Response:

## 4. 前端實作

| 檔案 | 說明 |
|------|------|
| `src/pages/eea-crm/CustomerMapPage.tsx` | 地圖頁面入口 |
| `src/components/crm/CustomerMap.tsx` | Leaflet 地圖元件（marker cluster、左側 Drawer、浮動選單、路線規劃） |

### 4.1 資料快取（IndexedDB）

- 首次載入從 API 取得全部 marker（精簡欄位：id, name, lat, lng, abc_grade, category, source, city, address, sales_rep, phone, status）
- 寫入 IndexedDB `CRMmap` 資料庫，`kv` object store，key=`crm_map_cache`
- 後續載入直接讀取 IndexedDB，秒開
- 快取有效期 1 小時
- 右上角 ↻ 按鈕可清除快取重新載入

### 4.2 左側 Drawer

Ant Design Drawer，`mask={false}` 不遮蓋地圖：

| 區塊 | 內容 |
|------|------|
| 🔍 搜尋 | 機構名稱或地址關鍵字搜尋 |
| **分類** | 全部 / A 類 / B 類 / C 類 / E 類（按鈕顯示統計數量） |
| **機構類型** | 2×3 grid checkbox：養護機構、居家服務、護理之家、長照機構、社區服務、其他 |
| **路線狀態** | 起點/終點設定顯示 + 計算路程 / 清除路線按鈕 |
| **📋 客戶詳情** | 點選 marker 後顯示名稱、負責人、地址、電話 |

### 4.3 地圖行為

- 初始載入：全臺視角
- Leaflet `preferCanvas: true` 提高 32k+ 標記效能
- **Marker Cluster**（leaflet.markercluster）：群聚顯示，避免卡頓
  - `chunkedLoading: true` 分批渲染
  - `disableClusteringAtZoom: 16`
  - `spiderfyOnMaxZoom: true`
- **ABC/E 分類篩選** + **機構類型篩選**（client-side 過濾）

### 4.4 浮動行動選單

點擊 marker 顯示浮動 Card，包含：

| 按鈕 | 功能 |
|:---|:---|
| 🚩 起點 | 設為路線起點，地圖顯示綠色圓點 +「🚩 起點」標籤 |
| 🎯 終點 | 設為路線終點，地圖顯示紅色圓點 +「🎯 終點」標籤 |
| 📅 行程規劃 | 觸發 `crm:schedule` CustomEvent |

### 4.5 路線規劃

- 起點/終點設定後，點擊左側 Drawer 的「計算路程」按鈕
- 若未設起點，自動以台灣福祉總部為起點
- 使用 **OSRM 免費 API** 計算實際道路路線
- 路線以藍色虛線繪製在地圖上
- 自動縮放至路線範圍
- 顯示預計車程（公里）與路程時間（小時/分鐘）
- 附註：本計算為參考路程及時間

### 4.6 台灣福祉總部標記

固定顯示於地圖，不因篩選而隱藏：
- 位置：24.9907, 121.4205（新北市樹林區）
- 紅色圓點 + 白心（自訂 DivIcon）
- 永久 Tooltip：「🏢 台灣福祉總部」
