# 客戶地圖規格

## 1. 概述

基於 Leaflet 的地圖視圖，呈現三源客戶的空間分布。支援 bbox 範圍查詢、來源/狀態/ABC 分級篩選、marker cluster 分群、點擊展開 Drawer 顯示客戶詳情。

## 2. 資料來源

地圖端點合併三源資料：

| 來源 | 顏色 | 資料取得方式 |
|------|:----:|-------------|
| 衛福部（mohw） | 🟢 #52c41a | ArangoDB crm_customers，source=mohw |
| 業務王（business_kindom） | 🟡 #fadb14 | ArangoDB crm_customers，source=business_kindom |
| Ragic（ragic） | 🔵 #1677ff | API 即時查詢（Data Agent proxy） |

## 3. API 端點

### GET /api/v1/crm/customers/map

Request:
```
bbox?      string  — "sw_lat,sw_lng,ne_lat,ne_lng"
source?    string  — mohw | business_kindom | ragic
status?    string  — potential | lead | customer
abc_grade? string  — A | B | C | E
city?      string  — 縣市
```

Response:
```json
{
  "markers": [
    {
      "id": "mohw_1S1500012",
      "source": "mohw",
      "status": "potential",
      "name": "機構名稱",
      "lat": 22.9874, "lng": 120.2114,
      "color": "#52c41a",
      "abc_grade": "B",
      "phone": "06-2143510",
      "address": "臺南市東區..."
    }
  ],
  "summary": {
    "total": 31400,
    "in_viewport": 342,
    "by_source": { "mohw": 300, "business_kindom": 30, "ragic": 12 }
  }
}
```

## 4. 前端實作

| 檔案 | 說明 |
|------|------|
| src/pages/eea-crm/CustomerMapPage.tsx | 地圖頁面入口 |
| src/components/crm/CustomerMap.tsx | Leaflet 地圖元件（marker cluster、bbox、篩選） |
| src/components/crm/AgentDrawer.tsx | 點擊 marker 展開 Drawer（客戶詳情 + 行程按鈕） |

### 地圖行為

- 初始載入：全臺視角，顯示所有來源
- 縮放/平移：自動觸發 bbox 查詢更新 markers
- Marker Cluster：避免 31K+ 筆導致卡頓
- Click Marker → AgentDrawer 展開
- Drawer 內含「行程」按鈕，點擊觸發 crm:schedule custom event
