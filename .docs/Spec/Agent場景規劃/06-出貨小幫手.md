# 06 — 出貨小幫手

> **Agent Key**: `shipping_assistant`
> **Endpoint**: `POST /shipping-assistant/chat`（建議）
> **Ragic 關聯**: ERP_26（銷貨單）、銷貨退回單
> **前端對應**: Data Agent Schema 分類歸入「進銷存」
> **狀態**: ⬜ 未實作

---

## 1. 概述

協助業務/倉管透過 LINE 查詢銷貨單出貨進度、銷貨退回狀態。全部為讀取操作。

### 負責業務邊界

```
業務/倉管在 LINE 上的出貨查詢需求
  ├── SO-008 出貨了嗎 → 查詢銷貨單出貨進度
  └── 退貨處理得如何 → 查詢銷貨退回狀態
```

### 不負責

- ❌ 建立/修改銷貨單
- ❌ 建立銷貨退回單
- ❌ 庫存查詢（由庫存小幫手負責）

---

## 2. 流程圖

```
User                    Agent                        Data Agent
 │                       │                             │
 ├─「SO-008 出貨沒？」─→│                             │
 │                       ├─ 判斷意圖: so_query         │
 │                       ├─ Data Agent NL→SQL ───────→│
 │                       │  (ERP_26 銷貨單)            │
 │                       │←─ return 銷貨狀態 ────────│
 │                       ├─ LLM 整理回應              │
 │←── 顯示出貨進度 ──────┤                             │
 │   已出貨 2026-05-06  │                             │
 │   配送: 貨運          │                             │
 │                       │                             │
 ├─「退貨處理得如何？」─→│                             │
 │                       ├─ 判斷意圖: so_return        │
 │                       ├─ Data Agent NL→SQL ───────→│
 │                       │  (銷貨退回單)               │
 │                       │←─ return 退貨狀態 ────────│
 │                       ├─ LLM 整理回應              │
 │←── 顯示退貨進度 ──────┤                             │
 │   退貨中，預計 05/10  │                             │
```

## 3. 狀態機 (SEQ)

```
銷貨單 (SO)
  ┌──────────┐
  │  訂單確認  │ ← 客戶下單確認
  └─────┬────┘
        │
  ┌─────▼────┐
  │  備貨中   │ ← 倉庫揀貨/包裝
  └─────┬────┘
        │
  ┌─────▼────┐
  │  已出貨   │ ← 貨運取件
  └─────┬────┘
        │
  ┌─────▼──────┐

        │
  ┌─────▼──┐

  └─────────┘
```

```
        │
  ┌─────▼──────┐

  └────────────┘
```

## 5. 意圖分類

| 意圖 | 觸發關鍵字 | 類型 | 資料來源 |
|------|-----------|------|---------|
| `so_query` | 銷貨, 出貨, 銷貨單, SO-, 出貨了嗎, 配送 | 讀取 | Data Agent（ERP_26） |
| `so_return` | 銷退, 退貨, 退回, 銷貨退回, SR- | 讀取 | Data Agent（銷退單） |
| `general_chat` | 其他 | 閒聊 | LLM 一般對話 |
