# 05 — 詢價小幫手

> **Agent Key**: `quotation_assistant`
> **Endpoint**: `POST /quotation-assistant/chat`（建議）
> **Ragic 關聯**: ERP_59（詢價單/報價憑證）、CONFIGURATIONFILE_10（供應商）
> **前端對應**: RagicLogisticProcess「詢價單」+「報價憑證」節點
> **狀態**: ⬜ 未實作

---

## 1. 概述

協助採購人員透過 LINE 查詢詢價單比價狀況、歷史報價記錄。全部為讀取操作，不需要確認機制。

### 負責業務邊界

```
採購人員在 LINE 上的詢價查詢需求
  ├── RFQ-001 有幾家報價 → 查詢詢價單報價狀況
  └── A001 上次買多少 → 查詢歷史報價/採購價格
```

### 不負責

- ❌ 建立/修改詢價單
- ❌ 發送詢價給供應商
- ❌ 建立採購單（由採購小幫手負責）

## 2. 流程圖

```
User                    Agent                        Ragic/Data Agent
 │                       │                             │
 ├─「RFQ-001 報價沒？」→│                             │
 │                       ├─ 判斷意圖: rfq_query        │
 │                       ├─ Data Agent NL→SQL ───────→│
 │                       │  (ERP_59 詢價單 + 供應商)   │
 │                       │←─ return RFQ status ──────│
 │                       ├─ LLM 整理比價摘要            │
 │←── 顯示報價狀況 ──────┤                             │
 │   已報: 3/5 家        │                             │
 │   最低: $15.5         │                             │
 │                       │                             │
 ├─「A001 上次買多少？」→│                             │
 │                       ├─ 判斷意圖: quote_query      │
 │                       ├─ Data Agent NL→SQL ───────→│
 │                       │  (歷史 PO + 報價憑證)       │
 │                       │←─ return 歷史價格 ────────│
 │                       ├─ LLM 整理價格趨勢            │
 │←── 顯示歷史價格 ──────┤                             │
 │   04/15 $15.5         │                             │
 │   03/20 $16.0         │                             │
```

## 3. 狀態機 (SEQ)

### 3.1 詢價單狀態

```
詢價單 (RFQ)
  ┌──────────┐
  │  報價中   │ ← 已發出，等待供應商報價
  └─────┬────┘
        │
  ┌─────▼──────┐
  │  比價完成   │ ← 已收集足夠報價
  │ (可轉採購)  │
  └─────┬──────┘
        │
  ┌─────▼──────┐
  │  已轉採購   │ ← 已依據比價結果建立採購單
  └─────┬──────┘
        │
  ┌─────▼──┐
  │  已結案  │
  └─────────┘
```

### 3.2 LINE 對話狀態機（純讀取）

```
  ┌────────────┐
  │    IDLE    │
  └─────┬──────┘
        │ 使用者查詢
  ┌─────▼──────┐
  │  INTENT    │ ← rfq_query / quote_query
  │ CLASSIFY   │
  └─────┬──────┘
        │
  ┌─────▼──────┐
  │  DATA AGENT│ ← 查 ERP_59 或歷史價格
  │   QUERY    │
  └─────┬──────┘
        │
  ┌─────▼──────┐
  │  RESPOND   │ ← LLM 整理比價/歷史價格
  └─────┬──────┘
        │
  ┌─────▼──────┐
  │    IDLE    │
  └────────────┘
```

## 4. LINE 對話範例

### 4.1 詢價單比價查詢

```
User > RFQ-202605001 有幾家報價了？

Agent > 詢價單 RFQ-202605001
       ─────────────────────────
       品項：A001 原料 x 1,000 KG
       發出對象：5 家供應商
       
       已報價（3 家）：
       1. XX食品 — $15.5/KG ⭐ 最低價
       2. YY原料 — $16.0/KG
       3. ZZ企業 — $16.8/KG
       
       未報價（2 家）：
       4. AA貿易 — 截止日 05/10
       5. BB公司 — 截止日 05/10
       
       最低價：$15.5/KG（XX食品）
       價差範圍：$15.5 ~ $16.8
       ─────────────────────────
```

### 4.2 歷史報價查詢

```
User > A001 原料之前買多少？

Agent > A001 原料 歷史採購價格：
       ─────────────────────────
       最近 3 筆：
       2026-04-15  XX食品  $15.5/KG  PO-202604015
       2026-03-20  YY原料  $16.0/KG  PO-202603020
       2026-02-10  XX食品  $15.8/KG  PO-202602010
       
       價格趨勢：近期價格平穩（$15.5~$16.0）
       ─────────────────────────
```

## 5. 意圖分類

| 意圖 | 觸發關鍵字 | 類型 | 資料來源 |
|------|-----------|------|---------|
| `rfq_query` | 詢價, RFQ-, 比價, 報價單, 詢價單 | 讀取 | Data Agent（ERP_59） |
| `quote_query` | 報價, 歷史價格, 之前買多少, 上次價格 | 讀取 | Data Agent（ERP_59 + ERP_13） |
| `general_chat` | 其他 | 閒聊 | LLM 一般對話 |

## 7. 確認機制

本 Agent **所有操作皆為讀取**，不需要寫入確認機制。

| 情境 | 處理方式 |
|------|---------|
| 查無詢價單 | 「查無 RFQ-XXX，請確認單號」 |
| 尚無報價 | 「RFQ-XXX 目前尚未收到報價」 |
| 查無歷史價格 | 「查無 A001 歷史採購記錄」 |
