# 10 — 出勤小幫手

> **Agent Key**: `attendance_assistant`
> **Endpoint**: `POST /attendance-assistant/chat`（建議）
> **Ragic 關聯**: CONFIGURATIONFILE_7（員工管理—班別欄位），打卡紀錄需確認資料來源（可能不在 Ragic）
> **狀態**: ⬜ 未實作
> **優先級**: P2（最低，需先確認打卡資料來源）
> **身份依賴**: ✅ 需要 `shared/user_binding.py`

---

## 1. 概述

協助員工透過 LINE 查詢個人出勤記錄與提交加班申請。出勤資料可能不在 Ragic（可能在門禁系統），實施前需先確認資料來源。

### 負責業務邊界

```
員工在 LINE 上的出勤需求
  ├── 我這個月打卡記錄 → 查詢出勤/打卡記錄（讀取）
  └── 我要報加班 → 提交加班申請（寫入，需確認）
```

### 不負責

- ❌ 修改打卡紀錄
- ❌ 排班管理
- ❌ 請假相關（由請假小幫手負責）

## 2. 流程圖

```
User                    Agent                        資料來源

 │                       │  (Ragic / 外部門禁 API)    │

 │   05/07 08:01 入      │                             │
 │   05/07 17:30 出      │                             │

### 2.2 加班申請流程（寫入，需確認）

```

 │                       │                             │

## 4. LINE 對話範例

### 4.1 出勤查詢

```
User > 我這週打卡記錄？

Agent > 您本週出勤記錄（王小明 EMP-00042）
       ─────────────────────────
       05/04(一) 08:02 入  17:28 出  ✅
       05/05(二) 07:55 入  17:32 出  ✅
       05/06(三) 08:10 入  17:30 出  ✅
       05/07(四) 08:01 入  17:25 出  ✅
       05/08(五) 尚未打卡
       ─────────────────────────
       本週工時：36.5 小時（不含今日）
       正常工時：40 小時
```

### 4.2 加班申請（含確認）

```
User > 我要報加班 5/7 18:00~21:00

Agent > 好的，以下是加班內容：
       ─────────────────────────
       員工：王小明（EMP-00042）
       日期：2026-05-07（四）
       時段：18:00 ~ 21:00（共 3 小時）
       類型：平日加班
       原因：趕訂單
       ─────────────────────────
       請問以上內容是否正確？
       (回覆「確認」以送出申請)

User > 確認

Agent > ✅ 加班申請已送出！
       申請單號：OT-20260507-0001
       狀態：待主管審核
```

## 5. 意圖分類

| 意圖 | 觸發關鍵字 | 類型 | 處理方式 |
|------|-----------|------|---------|
| `attn_query` | 打卡, 出勤, 刷卡, 遲到, 工時 | 讀取 | 查門禁系統 API / Ragic |
| `ot_apply` | 加班, 報加班, OT, 加班申請 | **寫入** | 摘要→確認→寫入 `overtime_requests` |
| `general_chat` | 其他 | 閒聊 | LLM 一般對話 |

## 7. 實施前注意事項

| 項目 | 說明 |
|------|------|
| **打卡資料來源** | 需確認 Ragic 是否有打卡記錄表，或需串接外部門禁系統 API |
| **班別資料** | Ragic 員工管理有「班別」欄位（Field ID: 1015499） |
| **加班類型** | 平日加班/假日加班/國定假日加班，費率不同 |
| **身份綁定** | 需要 user_binding 才能查個人資料 |
