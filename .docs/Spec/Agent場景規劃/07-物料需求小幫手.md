# 07 — 物料需求小幫手

> **Agent Key**: `mrp_assistant`
> **Endpoint**: `POST /mrp-assistant/chat`（建議）
> **Ragic 關聯**: ERP_42（物料需求單）、ERP_41（採購預算表）
> **前端對應**: RagicLogisticProcess「物料需求單(MRP)」→「採購預算表」節點
> **狀態**: ⬜ 未實作
> **LINE 適用性**: ⭐（偏低，偏向規劃性質）

---

## 1. 概述

協助生管/採購主管透過 LINE 查詢物料需求缺口和採購預算使用狀況。全部為讀取操作。

### 負責業務邊界

```
生管/採購主管在 LINE 上的物料查詢需求
  ├── 本月物料需求 → 查詢 MRP 料況缺口
  └── 預算剩多少 → 查詢採購預算使用狀況
```

### 不負責

- ❌ 執行 MRP 運算
- ❌ 建立/修改採購預算表
- ❌ 建立採購單（由採購小幫手負責）

## 2. 流程圖

### 2.1 物料需求查詢

```
User                    Agent                        Data Agent (Pandas)
 │                       │                             │
 ├─「本月物料需求？」─→│                             │
 │                       ├─ 判斷意圖: mrp_query        │
 │                       ├─ Data Agent Pandas ───────→│
 │                       │  (MRP 展開: BOM→庫存→缺口) │
 │                       │←─ return 料況缺口 ────────│
 │                       ├─ LLM 整理為摘要              │
 │←── 顯示料況缺口 ──────┤                             │
 │   A001 缺口 3,500KG  │                             │
 │   B002 缺口 7,000 個 │                             │
```

### 2.2 預算查詢

```
User                    Agent                        Data Agent
 │                       │                             │
 ├─「採購預算還有多少？」→│                             │
 │                       ├─ 判斷意圖: budget_query     │
 │                       ├─ Data Agent NL→SQL ───────→│
 │                       │  (ERP_41 預算 + 已用 PO)   │
 │                       │←─ return 預算統計 ────────│
 │                       ├─ LLM 整理回應              │
 │←── 顯示預算狀況 ──────┤                             │
 │   已用 $320K/500K     │                             │
 │   剩餘 $180K          │                             │
```

## 3. 狀態機 (SEQ)

### 3.1 MRP 狀態

```
物料需求單 (MRP)
  ┌──────────┐
  │  試算中   │ ← BOM 展開計算中
  └─────┬────┘
        │
  ┌─────▼────┐
  │  已發佈   │ ← 料況缺口已產出
  │ (有缺口)  │
  └─────┬────┘
        │ 缺口已轉採購
  ┌─────▼──────┐
  │  採購處理中  │ ← 已建立對應採購單
  └─────┬──────┘
        │
  ┌─────▼──┐
  │  已結案  │ ← 需求已滿足
  └─────────┘
```

### 3.2 LINE 對話狀態機（純讀取）

```
  ┌────────────┐
  │    IDLE    │
  └─────┬──────┘
        │ 使用者查詢
  ┌─────▼──────┐
  │  INTENT    │ ← mrp_query / budget_query
  │ CLASSIFY   │
  └─────┬──────┘
        │
  ┌─────▼──────┐
  │  PANDAS    │ ← MRP 需 Pandas 引擎
  │  ENGINE    │   （BOM 展開 + 庫存扣抵）
  └─────┬──────┘
        │
  ┌─────▼──────┐
  │  RESPOND   │ ← LLM 整理缺口摘要
  └─────┬──────┘
        │
  ┌─────▼──────┐
  │    IDLE    │
  └────────────┘
```

```
User > 這個月的物料需求出來了嗎？

Agent > 本月物料需求單 MRP-202605
       ─────────────────────────
       品項             需求      庫存      缺口
       A001 原料      5,000KG   1,500KG   3,500KG  ⚠️
       B002 包材     10,000個   3,000個   7,000個  ⚠️

       建議採購總金額：約 $85,000
```

```
Agent > 本月採購預算使用狀況：
       ─────────────────────────

       已使用：$320,000（已成立採購單）
       　　　　├ PO-202605001 $150,000

       　　　　└ PO-202605003  $50,000
       剩餘：$180,000

       ─────────────────────────
```

## 5. 意圖分類

| 意圖 | 觸發關鍵字 | 類型 | 資料來源 |
|------|-----------|------|---------|
| `mrp_query` | 物料需求, MRP, 料況, 需求單, 缺口 | 讀取 | Data Agent Pandas |
| `budget_query` | 預算, 採購預算, 預算表, 還有多少錢 | 讀取 | Data Agent（ERP_41 + ERP_13） |
| `general_chat` | 其他 | 閒聊 | LLM 一般對話 |
