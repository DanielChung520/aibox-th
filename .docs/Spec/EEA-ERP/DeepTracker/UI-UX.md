## 4. NL 自然語言輸入面板

### 4.1 佈局

```
+------------------------------------------------------------------+
|  🔍 自然語言查詢 (輔助輸入)                                      |
|  +------------------------------------------------------------+  |
|  |                                                             |  |
|  |  追蹤進料批號 B001 看看用了哪些原料、產出什麼成品             |  |
|  |                                                             |  |
|  +------------------------------------------------------------+  |
|  [🔎 解析並查詢]                               [💡 範例查詢 ▼]  |
+------------------------------------------------------------------+
```

### 4.2 行為

1. 使用者輸入自然語言句子
2. 點擊「解析並查詢」→ 呼叫 `/trace-engine/nl-parse`
3. 解析成功 → 自動選中對應場景 + 填入參數 → 自動開始追蹤
4. 解析失敗 → 顯示 `⚠️ 無法解析，請嘗試：追蹤批號 XXX` 提示

### 4.3 範例查詢下拉

| 範例 | 解析結果 |
|------|----------|
| 追蹤批號 B001 | 自動: 進料批號追蹤 + batch_no=B001 |
| 這批貨出給誰了 | 自動: 出貨批號追蹤（需先有批號上下文） |
| 查詢成品 A 的完整履歷 | 自動: 成品全履歷 + product_code=A |
| 供應商 ABC 的料做了哪些成品 | 自動: 供應商追溯 + supplier=ABC |

| **儲存** | 僅在使用者點擊「儲存報告」按鈕時觸發 — 永不自動儲存 |
| **載入** | 從 ArangoDB 讀取 TraceResult → 重新渲染圖譜 + 表格 |
| **刪除** | 二次確認後從資料庫刪除 |
| **大報告處理** | >500 nodes 時摘要儲存於 ArangoDB，完整資料提醒使用者 |
