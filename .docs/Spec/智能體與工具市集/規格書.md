## 1. 定位與角色

### 1.1 服務定位

**效能工具代理**（Performance Advisor Agent）是 AIBox 系統中的輕量級效能顧問 Agent，專門在複雜查詢決策、Bug 分析、架構建議等場景下提供深層分析。

- **整合方式**：以 FastAPI service 形式存在，掛載於 Data Agent service 底下（`/advisor` 端點）
- **部署位置**：與 Data Agent 共用同一 service，port 8003
- **模型**：使用 `small_llm_model` 處理一般建議，`large_llm_model` 處理深層分析
- **設計原則**：Read-only顧問，不寫入任何資料，只讀取、提供建議

### 1.2 系統架構位置

```
TopOrchestrator (意圖路由)
    ├── Data Agent (NL→SQL)
    │   ├── /query/nl2sql      — NL→SQL 執行管線
    │   ├── /intent-rag        — 意圖匹配
    │   └── /advisor           — 效能顧問 ⭐
    ├── Knowledge Agent (知識庫)
    └── BPA MM Agent (物料管理)
```

### 1.3 能力邊界

| 能力 | 說明 |
|------|------|
| ✅ AQL/SQL 效能分析 | 分析查詢計劃瓶頸、提出優化建議 |
| ✅ 意圖匹配失敗分析 | 為何 Qdrant 匹配分數低，給出改進建議 |
| ✅ Schema 問題診斷 | 欄位 ID 不匹配、資料型別問題 |
| ✅ 架構決策顧問 | template / small LLM / large LLM 策略選擇 |
| ✅ 深層 Bug 分析 | 同一錯誤發生 2 次以上的根本原因 |
| ❌ 不寫入資料 | 純顧問，不修改任何資料 |
| ❌ 不執行命令 | 只給建議，不執行 AQL/SQL |

## 2. 觸發條件（Trigger Conditions）

觸發分為**自動觸發**（系統事件）和**手動觸發**（使用者請求）。

### 2.1 自動觸發條件

| ID | 條件 | 閾值 | 行為 |
|----|------|------|------|
| T-01 | 查詢執行時間超過 | 5 秒 | 附效能分析建議到結果 |
| T-02 | 同一意圖匹配分數低於 | 0.5 | 提供意圖改進建議 |
| T-03 | 查詢結果為空且使用了 template 策略 | — | 分析原因並建議 |
| T-04 | 欄位 ID 映射失敗（AQL 無法執行） | — | 提供 schema 更新建議 |
| T-05 | Pipeline Phase 失敗 | — | 深層分析錯誤根因 |
| T-06 | 同一 Intent 連續 2 次匹配失敗 | — | 提供意圖重訓練建議 |

### 2.2 手動觸發

| ID | 觸發方式 | 端點 |
|----|---------|------|
| M-01 | 使用者發送以 `@效能顧問` 開頭的查詢 | `POST /advisor/query` |
| M-02 | 使用者點擊「深層分析」按鈕 | `POST /advisor/analyze` |

### 2.3 觸發優先順序

```
使用者手動請求 (M-01/M-02)
    ↓ 最高優先，強制執行
自動觸發 (T-01 ~ T-06)
    ↓ 中等優先，視負載決定
非必要Advisor (背景分析)
    ↓ 最低優先，排程處理
```

## 4. 整合方式

### 4.1 整合進 NL2SQL Pipeline

在 `orchestrator.py` 的 Pipeline 執行後，根據觸發條件自動呼叫 Advisor：

```python
# orchestrator.py — Pipeline 尾端
async def run_nl2sql_pipeline(...):
    result = execute_pipeline(...)
    
    # 觸發 Advisor（如果滿足條件）
    if _should_trigger_advisor(result):
        advice = await call_advisor(result)
        result.advisor_insights = advice
    
    return result
```

### 4.2 觸發條件實作

```python
def _should_trigger_advisor(result: PipelineResult) -> bool:
    if result.execution_time_ms > 5000:        # T-01
        return True
    if result.row_count == 0 and result.strategy == "template":  # T-03
        return True
    if result.best_intent_score < 0.5:          # T-02
        return True
    if result.phase_errors:                     # T-05
        return True
    return False
```

### 4.3 非同步整合（不阻塞主 Pipeline）

Advisor 回呼透過 FastAPI `BackgroundTasks` 執行，結果寫入 Pipeline Result 的 `advisor_insights` 欄位（不影響主要回應速度）。

## 5. 系統參數

| 參數 Key | 說明 | 預設值 |
|---------|------|--------|
| `da.advisor_enabled` | 是否啟用效能顧問 | `true` |
| `da.advisor_auto_trigger` | 是否自動觸發 | `true` |
| `da.advisor_slow_query_ms` | 慢查詢閾值（毫秒） | `5000` |
| `da.advisor_low_score` | 低分數閾值 | `0.5` |
| `da.advisor_model` | 使用的模型 | `qwen2.5-coder:7b` |
| `da.advisor_large_model` | 深層分析模型 | `qwen2.5-coder:14b` |

---

## 6. 錯誤處理

| 錯誤碼 | 說明 | 降級策略 |
|--------|------|----------|
| `ADVISOR_TIMEOUT` | Advisor 回應超時 | 返回 `null advisor_insights`，主流程不受影響 |
| `ADVISOR_LLM_ERROR` | LLM API 錯誤 | 記錄日誌，返回空建議 |
| `ADVISOR_DISABLED` | 功能已停用 | 跳過 Advisor 呼叫 |

---

## 7. 日誌與監控

- 所有 Advisor 呼叫寫入 `advisor_calls` 集合（ArangoDB）
- 欄位：`advisor_id`, `query`, `nl_query`, `latency_ms`, `severity`, `model_used`, `created_at`
- Metrics：`advisor_calls_total`, `advisor_latency_ms`, `advisor_trigger_rate`

---

## 8. 實作規劃

| Phase | 內容 | 優先度 |
|-------|------|--------|
| Phase 1 | 建立 Advisor Service（`/advisor/query` 端點） | P0 |
| Phase 2 | 整合進 NL2SQL Pipeline（T-01, T-03 觸發） | P0 |
| Phase 3 | `/advisor/analyze` 端點實作 | P1 |
| Phase 4 | `/advisor/check-schema` 端點實作 | P1 |
| Phase 5 | T-02, T-04, T-06 觸發條件 | P2 |
| Phase 6 | 系統參數配置頁面整合 | P3 |

## 附錄 A：Advisor Prompt 模板

### 一般效能建議
```
你是一個效能顧問。根據以下資訊，提供效能優化建議。

查詢計劃：
{query_plan}

執行時間：{execution_time_ms}ms
返回行數：{row_count}
錯誤（如有）：{error}

請分析：
1. 主要效能瓶頸
2. 具體優化建議（最多 3 條）
3. 預期改善幅度

以 JSON 格式回應。
```

### 意圖匹配分析
```
你是一個意圖匹配專家。使用者輸入「{nl_query}」，系統匹配到「{intent_id}」（分數 {score}）。

請分析：
1. 為何分數低於預期
2. 如何改善 nl_examples 或 schema
3. 是否需要新增意圖

以 JSON 格式回應。
```
