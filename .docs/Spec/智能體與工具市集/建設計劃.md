## 0. 設計原則

1. **外部工具**（Weather、Web Search、Email、LINE 等）→ 串接外部 API，有實際資料流
2. **內部顧問**（流程、審計、決策等）→ 以 LLM 推理為主，Read-only 顧問
3. **深度流程顧問**（Oracle Agent）→ 最高優先，負責複雜架構決策與計劃審計

---

## 1. 工具分類

### 1.1 分類定義

| 分類 | 說明 | 範例 |
|------|------|------|

| **Internal Advisor** | LLM 推理為主，Read-only 顧問 | DS Advisor, Process Advisor, Audit Advisor |
| **Oracle Agent** | 深度流程顧問，負責計劃審計與複雜決策 | Deep Process Advisor |

## 2. Oracle Agent（深度流程顧問）— 最高優先

### 2.1 定位

| 項目 | 說明 |
|------|------|
| **名稱** | Deep Process Advisor（深度流程顧問） |
| **角色** | Oracle Agent — Read-only 顧問 |
| **職責** | 複雜架構決策、計劃審計、Bug 根因分析 |
| **觸發方式** | 自動（錯誤發生 2+ 次）+ 手動（@深度顧問） |

### 2.2 能力邊界

| 能力 | 說明 |
|------|------|
| ✅ 架構決策顧問 | 系統設計、技術選型、遷移策略 |
| ✅ 計劃審計 | 審查其他 Agent 的工作計劃，合規性檢查 |
| ✅ Bug 分析 | 錯誤發生 2 次以上時的根因分析 |
| ✅ 流程優化建議 | 業務流程瓶頸識別與改進建議 |
| ❌ 不寫入資料 | 純顧問，不修改任何系統狀態 |
| ❌ 不執行命令 | 只給建議，不直接操作系統 |

## 4. 授權與權限模型

### 4.1 授權模式

每個工具/顧問都有 `visibility` 欄位，控制誰可以調用：

| 模式 | `visibility` 值 | 說明 |
|------|-----------------|------|
| **公開** | `public` | 所有已登入帳號都可以調用 |
| **角色授權** | `role` | 需在 `visibility_roles` 中聲明的角色才能調用 |
| **帳號授權** | `account` | 需在 `visibility_accounts` 中聲明的帳號才能調用 |

### 4.2 授權檢查流程

```python
async def check_tool_authorization(
    tool_key: str,
    user: User,
) -> bool:
    """
    檢查使用者是否有權限調用特定工具
    
    流程：
    1. 取得工具的 visibility 配置
    2. 若為 public → 允許
    3. 若為 role → 檢查 user.role_key 是否在 visibility_roles 中
    4. 若為 account → 檢查 user.username 是否在 visibility_accounts 中
    5. 若都不符合 → 拒絕訪問
    """
    tool = await get_tool_from_db(tool_key)
    
    if tool.visibility == "public":
        return True
    
    if tool.visibility == "role":
        return user.role_key in tool.visibility_roles
    
    if tool.visibility == "account":
        return user.username in tool.visibility_accounts
    
    return False
```

### 4.3 預設權限配置

| 工具 | 預設權限 | 說明 |
|------|----------|------|
| 天氣預報 | `public` | 所有人均可使用 |
| 網路搜尋 | `public` | 所有人均可使用 |
| **深度流程顧問** | `role` | 僅管理員與特定角色 |
| 資料科學顧問 | `role` | 僅分析師角色 |
| 流程顧問 | `role` | 僅流程管理員 |
| 審計顧問 | `role` | 僅稽核角色 |
| 決策顧問 | `role` | 僅管理層角色 |
| 會議記錄助手 | `role` | 僅行政角色 |
| 郵件助手 | `account` | 僅本人使用 |
| LINE 助手 | `account` | 僅本人使用 |

### 4.4 API 端點權限控制

所有 `/api/v1/tools/{tool_key}/*` 端點都需經過授權檢查：

```python
@app.middleware
async def check_tool_access(request: Request, call_next):
    if "/tools/" in request.url.path:
        tool_key = extract_tool_key(request.url.path)
        user = get_current_user(request)
        
        if not await check_tool_authorization(tool_key, user):
            return JSONResponse(
                status_code=403,
                content={"code": 403, "message": "無權限訪問此工具"}
            )
    
    return await call_next(request)
```
