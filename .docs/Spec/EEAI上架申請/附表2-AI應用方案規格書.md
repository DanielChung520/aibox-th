## 預期可解決之產業痛點

1. **資料孤島**：企業內部 ERP、CRM、資料庫各自獨立，難以統一查詢分析
2. **AI 幻覺**：傳統 AI 系統可能產生錯誤或不精確的回答，影響企業決策
3. **資料外洩疑慮**：使用雲端 AI 服務時，企業敏感資料可能外流
4. **SQL 門檻高**：非技術人員難以直接查詢企業資料庫
5. **流程效率低**：重複性作業與審核流程耗費大量人力

## 演算法與模型

| 類別 | 說明 |
|------|------|
| ☑ 鑑別式（機器學習、深度學習） | 向量檢索、圖譜抽取、意圖分類、NL→SQL 驗證 |
| ☑ 生成式 AI（含Agentic AI） | 本地模型：Ollama (Llama 2/3, Mistral, Qwen) / LM Studio<br>雲端模型：OpenAI GPT-4、阿里 DashScope (通義千問) |

**具體說明：**
- 向量檢索：Sentence Transformers (all-MiniLM-L6-v2)
- 圖譜抽取：自建 NLP 實體識別模型
- 基礎模型不做資料訓練用途，僅用於推理

## 流程設計與導入說明

### 系統架構（三層分離）

1. **應用層**：Tauri 桌面端 + Web 介面
2. **代理層**：Knowledge Agent、Data Agent、BPA Agent、MCP Tools
3. **模型層**：Hybrid RAG、LLM Router、Embedder

### 導入流程

| 階段 | 說明 | 時間 |
|------|------|------|
| 環境評估 | 確認企業資料源、網段架構、資安需求 | 1-2 天 |
| 系統部署 | 安裝 EEA 平台、串接企業資料庫、設定模型 | 3-5 天 |
| 知識庫建置 | 上傳企業文件、建立知識圖譜、測試 RAG 效果 | 5-10 天 |
| 教育訓練 | 操作培訓、代理建立教學、進階功能說明 | 2-3 天 |
| 上線支援 | 技術諮詢、效能優化、版本更新 | 持續 |

**總導入時間：約 15-25 個工作天**

## 與市場相關產品比較

| 特色 | EEAI | 一般 AI 助理 |
|------|------|--------------|
| 資料主權 | 完全本地部署，資料不出防火牆 | 多為雲端，資料經過第三方 |
| RAG 技術 | 雙軌 RAG（向量+圖譜），Hallucination < 5% | 單軌向量檢索 |
| 企業原生設計 | RBAC、審計追蹤、SELECT-only SQL | 通用 AI 助理 |
| 流程自動化 | 原生 BPA 支援 | 僅對話式 AI |
| 系統串接 | MCP Tools 生態，開放工具註冊 | 有限整合能力 |
