## 產品資訊

**產品名稱**：Edge Enterprise AI (EEAI)
**官方網站**：https://edges.ent4i.com
**技術文件**：https://gamma.app/docs/Edge-Enterprise-AI-o63npsyf1kqd49f

### 核心功能模組
1. Hybrid Model Hub - 混合模型架構
2. Knowledge Hub - 知識庫管理
3. Hybrid RAG - 雙軌檢索增強生成
4. Data Agent - 自然語言資料查詢
5. MCP Tools - 微能力工具平台
6. BPA - 企業流程自動化

### 技術架構
- 前端：React + TypeScript + Tauri
- 後端：Python FastAPI + Rust Axum
- AI/ML：LangChain + Ollama + Sentence Transformers
- 資料庫：Qdrant + ArangoDB + PostgreSQL
