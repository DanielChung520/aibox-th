# 05｜工具市集 x 資料追蹤：從 LINE 到退貨追蹤

## 旁白稿（約 220 字 / 60 秒）

> 中小企業想導入 AI，
> 難道一定得先建置大型系統？
>
> [uv_break]EEA 不這麼認為。
>
> 我們內建大量工具，[uv_break]
> 工具是無狀態的，專注完成單一事件，
> 清楚、可控、可預期。
>
> 而且可以直接嵌入 LINE、微信、DingTalk、WhatsApp。
> [uv_break]你可以在通訊軟體裡，
> 建立客服、訂單、庫存等多個服務頻道。
>
> 不只通訊，EEA 也打通了資料這關。
>
> EEA for Ragic 已經將資料表關聯接入知識圖譜。
> [uv_break]當一張訂單被退貨，
> 系統不只是看到一筆異常，
> 而是沿著關聯路徑，自動追溯——
> [uv_break]生產批次、原料供應商、目前庫存、
> 已出貨數量、受影響的客戶範圍。
>
> [uv_break]從通訊到資料，從日常到追蹤。
> 中小企業也能逐步建立自己的智能營運能力。

## 建議畫面
- 開場：小辦公室，一人多工忙亂畫面
- 轉場：手機 LINE/WhatsApp 對話，AI 助手即時回覆
- 多個服務 Channel 圖示展開
- 轉場到資料畫面：一張退貨訂單亮紅燈
- 資料圖譜動畫：紅色路徑自動延伸（批次→供應商→庫存→客戶）
- 結尾：全景圖，通訊+資料雙軌並行
