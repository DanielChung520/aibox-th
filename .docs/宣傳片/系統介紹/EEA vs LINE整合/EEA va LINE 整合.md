# EEA ⨯ LINE 整合：AI 小助手頻道管理

## 功能介紹

## 對應畫面

- EEA 後台：LINE Channel 設定頁面，卡片式管理 4 個頻道
- 每個頻道對應一組業務場景（定制小助手、採購小助手、Ragic 小助手、ESG 小助手）
- 切換至 LINE App，直接與小助手對話

## 核心功能

| 功能         | 說明                                 |
| ------------ | ------------------------------------ |
| 多頻道管理   | 同時管理多個業務場景的 AI 助手       |
| 零學習成本   | 員工在 LINE 上直接使用，無需額外安裝 |
| 後台一鍵設定 | Channel 啟用 / 停用、新增、編輯      |
| 場景擴展     | 可依企業需求新增客製化小助手         |
