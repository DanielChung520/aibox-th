## 使用方式

本表用途是讓你直接安排錄製與蒐集素材。

每段包含：

- 時間碼
- 畫面目標
- 建議錄製內容
- 補充素材
- 後製提示

建議你先依這張表收素材，再決定哪些段落要：

- 實拍
- 螢幕錄影
- UI 特寫
- 動畫補足

## 優先錄製清單

如果你時間有限，先錄這 8 類：

1. 多系統切換與輸入停頓
2. AI 對話 + 風險感畫面
3. EEA 主畫面 / 首頁 / 總覽
4. 文件上傳與知識庫畫面
5. ontology / graph 畫面
6. Ragic 表格與追溯流程
7. tools / agents / workflow 畫面
8. 艾企助手浮動互動畫面

---

## 錄製建議

### 螢幕錄製

- 解析度至少 1440p，最好 4K
- 滑鼠移動不要太急
- 點擊要明確
- 每個操作段落前後多留 2~3 秒空白

### UI 錄製

- 盡量避免真實敏感資料
- 若需示範，請先用測試資料或可公開內容
- 同一段操作最好錄 2~3 次，方便剪輯

### 實拍鏡頭

- 以手部、側臉、螢幕反光、工作桌面為主
- 不一定要很多演員，少量真實工作感即可
- 重點是「企業日常壓力」與「流程被串起來後的秩序感」

---

## 後製提醒

- 問題段剪快
- 系統段剪穩
- 圖譜、邊界、流程建議交給後製補動畫
- UI 不要全畫面停太久，避免像教學影片
- 最後 30 秒一定要留給品牌收束，不要塞新資訊
