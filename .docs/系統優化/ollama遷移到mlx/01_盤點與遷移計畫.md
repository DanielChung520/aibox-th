## 五、風險與注意事項

1. **`/api/generate`** 是 Ollama 專有 API，MLX-LM 不支援。所有 `/api/generate` 呼叫需改為 `/v1/chat/completions`（改 prompt 結構，加入系統訊息）。
2. **`/api/embed`** 改為 `/v1/embeddings`（OpenAI 格式），需確認 MLX embedding endpoint 格式。
3. **`langchain_ollama.ChatOllama`** 是 aitask 的相依套件，需改為 `langchain_openai` 或直接 httpx 呼叫。
4. **Vision 模型**：MLX 有 `mlx-vlm` 套件支援 minicpm-v、LLaVA 等，API 格式與 Ollama 不同。
5. **自定義 modelfile**：`qwen3-coder-report` 是從 `qwen3-coder:30b` 建立的 custom modelfile，MLX 無法直接讀取需轉換。
