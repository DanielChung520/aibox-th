# oMLX 遷移測試計畫

> 對應：01_盤點與遷移計畫.md
> 最後更新：2026-06-22
> 測試時機：oMLX Server (port 11400) 已上線
> 策略：先測 oMLX 服務本身，再測專案整合

## 當前架構（2026-06-22）

```
LINE 圖片 → Qwen3-VL-8B（multimedia analyzer）
  ├→ 名片 → 提取姓名/職稱 → 回覆生成（同模型）
  ├→ 賀卡 → 文學回覆
  └→ 一般 → 感謝分享
  
LINE 文字 → 意圖分類 → Qwen3-Coder-30B（call_llm）
  ├→ company_intro → HybridRAG 知識庫
  ├→ general_chat → LLM 回覆
  └→ 其他意圖 → 對應 handler
```

| 服務 | Port | 用途 | 模型 |
|------|------|------|------|
| oMLX | 11400 | 主推理服務 | Qwen3-Coder-30B, Qwen3-VL-8B, bge-m3, TTS×3 |
| Ollama | 11434 | ⛔ 已停用（全部遷移至 oMLX） | — |
| OCR | 11401 | ⛔ 已停用（VL 取代） | — |
| unified_agents | 8011 | LINE 助理 | — |
| API Gateway | 6500 | Rust 入口 | — |

## 模型對照：Ollama → oMLX

> 原始計畫基於 Ollama 的模型名稱已全部變更，以下為實際啟用中的 oMLX 模型。

| 用途 | oMLX 模型 ID | 來源 | 大小 | 說明 |
|------|-------------|------|------|------|
| 主力 LLM | `Qwen3-Coder-30B` | `mlx-community/Qwen3-Coder-30B-A3B-Instruct-4bit` | 16.8 GB | MoE 架構（活躍 3B/次） |
| Vision | `Qwen3-VL-8B` | `mlx-community/Qwen3-VL-8B-Instruct-4bit` | 5.8 GB | 支援 Thinking 模式 |
| Embedding | `bge-m3` | `mlx-community/bge-m3-mlx-fp16` | 1.1 GB | 維度 1024 |
| TTS（未測試） | `mlx-community--Qwen3-TTS-*` | HuggingFace | 三種變體 | 語音合成，本次不測 |
