# MLX-LM 遷移測試計畫

> 對應：01_盤點與遷移計畫.md
> 最後更新：2026-06-22
> 測試時機：MLX Server (port 11400) 已上線
> 策略：先測 MLX 服務本身，再測專案整合

## 當前架構（2026-06-22）

```
LINE 圖片 → Qwen3-VL-8B（multimedia analyzer）
  ├→ 名片 → 提取姓名/職稱 → 回覆生成（同模型）
  ├→ 賀卡 → 文學回覆
  └→ 一般 → 感謝分享
  
LINE 文字 → 意圖分類 → Qwen3-Coder-30B（call_llm）
  ├→ company_intro → HybridRAG 知識庫
  ├→ general_chat → LLM 回覆
  └→ 其他意圖 → 對應 handler
```

| 服務 | Port | 用途 | 模型 |
|------|------|------|------|
| oMLX | 11400 | 主推理服務 | Qwen3-VL-8B, Qwen3-Coder-30B |
| Ollama | 11434 | Embedding 專用（待遷移） | bge-m3 |
| OCR | 11401 | ⛔ 已停用（VL 取代） | — |
| unified_agents | 8011 | LINE 助理 | — |
| API Gateway | 6500 | Rust 入口 | — |
