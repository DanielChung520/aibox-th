## 4️⃣ 差異分類總結

| 差異類型 | 等級 | 說明 |
|----------|------|------|
| **欄位結構** | ✅ 無差異 | 所有共同表單的 Field ID/Type/Writable 完全相同 |
| **Loaded Field Invalid** | ⚠️ 中等 | 兩邊都有相同問題，需重建 Link |
| **Sheet 命名** | ✅ 僅命名 | 不影響功能 |
| **Sheet 增刪** | 🟡 輕微 | 各自多了不同的業務表單 |
| **dawnlink 多了** | 🟢 研發/設備 | Q-4-Q-12-xx 系列、設備相關 |
| **2025shianyong 多了** | 🟢 衛生安全 | G-4-1-xx、G-4-4-xx 系列 |
