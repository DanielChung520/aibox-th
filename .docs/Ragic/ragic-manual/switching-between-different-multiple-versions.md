## 多版本表單是什麼？

多版本表單是指共享同一組資料的不同版本表單，主要是用來讓不同使用者群組根據各自需求看到不同版本的表單內容。當使用者在其中一個表單新增資料或是編輯欄位資料時，同時也會在另一個多版本表單新增資料或是更新有相同欄位的資料。

左側工具列上的這個圖示代表和目前表單使用相同一組資料的多版本表單。只要點擊它就可以快速切換至所選擇的多版本表單。
