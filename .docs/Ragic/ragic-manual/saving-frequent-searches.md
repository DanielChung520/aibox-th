## 自訂篩選

在左側搜尋列可以針對表單內的多個欄位下條件來搜尋。當你有自己常用的搜尋條件時，可以將這些常用的篩選條件儲存為自訂篩選，下次只要點選儲存的篩選，就會自動套用這個搜尋條件。

在左側搜尋列設定好搜尋條件後，點擊儲存篩選條件，在視窗內輸入想要的篩選名稱。

儲存的自訂篩選會列在左側搜尋選項的上方，這個儲存的條件只有你可以看到，也就是屬於你自己的篩選選單。點擊篩選就會自動套用搜尋條件。

點選清除篩選與排序即可取消篩選。

如果要刪除自訂篩選，在自訂篩選的名稱按右鍵或是點擊旁邊的箭頭，選擇移除自訂篩選。

如果想要更新篩選條件，可以在自訂篩選的名稱按右鍵或是點擊旁邊的箭頭，選擇更新此篩選。

若是有常用的篩選條件，希望能讓其他使用者也能一起使用的話，可以請SYSAdmin系統管理者/表單設計者新增共通篩選。

如果想把套用的共通篩選結果分享給他人的話。例如想給別人查看在職狀態是｢在職」的人事資料時。就可以使用分享共通篩選網址的功能。

另外也可以透過共通篩選資料通知，系統會在有新資料符合此篩選條件，或是從符合變成不符合的時候寄送通知。

你可以在篩選名稱上按右鍵，或點擊旁邊的箭頭並選擇 重新排序，來重新排序儲存的自訂篩選或共通篩選。

接著就可以在篩選列表中拖曳篩選來調整順序，完成後點擊儲存排序。

需要注意的是，自訂篩選與共通篩選的排序是分開管理的，無法一起排序。
