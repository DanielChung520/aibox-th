## 請針對上方勾選項目提供詳細說明：

要下載檔案上傳欄位或圖片上傳欄位中的所有檔案的話，你可以在列表頁點選工具 > 匯出 > 下載附件。

在視窗中選擇要下載的欄位及資料範圍(一般欄位或子表格欄位皆可)，下載下來後會是 .zip 的壓縮檔，解壓縮就能看到各筆檔案。

如果曾經在多筆檔案上傳上傳過對應檔(mapping.xlsx)，也可以選擇加入對應檔並選擇對應欄位(Key欄位)就可以將對應檔一起下載至.zip的壓縮檔中。
