## 通知設定

   1. 使用者通知狀態

   2. 頁籤個別設定

   3. 總體通知設定

你可以從個人設定中的通知設定來設定你是否要收到系統通知(通知的事件如：資料修改、簽核、留言等)，各頁籤中的個別表單資料新增和修改時是否要收到通知，以及針對各種通知事件，要如何收到通知。

以下介紹三種不同的通知設定：

可以透過使用者通知狀態直接設定你是否要收到任何通知(例如：提醒、傳閱、簽核、回應、跟你有關的資料修改等)。

點擊「取消通知」後，狀態會變成停止，就不會收到任何通知，也無法調整下面兩個部分的通知設定。點擊「恢復通知」便回到可以收到通知的狀態。

選擇想要設定通知的表單所在頁籤。

針對頁籤中的個別表單設定是否要收到以下四種情況的通知：

1. 跟我相關的資料修改時通知我(預設開啟)

2. 有任何新的一筆資料通知我

3. 任何資料有修改的時候通知我

4. 有人回應跟我相關的資料時通知我(預設開啟)

備註：跟我相關的資料包含：我新增的資料、被指派給我的資料、我回應過的資料。

設定哪些通知事件發生時，系統以什麼方式發出通知( E-mail、手機 app 推播、網頁通知、LINE)，每個通知事件都可以勾選希望收到通知的方式。

有勾選的話會收到E-mail通知信件。

勾選的話會傳送手機 app 推播通知。如果想要收到推播通知，請先安裝 Ragic 的手機 app （iOS 系統下載地址、Android 系統下載地址），並確認手機上 Ragic app 的通知設定是否有打開。

勾選的話可以從資料庫畫面右上方的鈴鐺圖示查看，點選後即可看到通知內容並連結到該筆資料。

請參考啟用 LINE 通知章節。

除了可以依據上述的三種情況來設定通知，或是 SYSAdmin 系統管理者/表單設計者有設定提醒通知以外，如果希望只針對篩選的資料進行通知的話，使用者可以針對表單上的共通篩選來設定接收通知。

點選共通篩選名稱旁的三角形圖示或是直接針對共通篩選名稱點右鍵，就可以找到通知我的選項。

共通篩選資料通知會在以下兩種情況寄送通知：

1.當有符合篩選的資料新增(新一筆資料/從不符合改成符合條件的編輯儲存)

2.本來符合篩選後來不符合(從符合改成不符合條件的編輯儲存)

如果要取消設定的通知的話，點選共通篩選名稱旁的三角形圖示或是直接針對共通篩選名稱點右鍵，選擇停止通知我即可。

1. 透過大量修改或是匯入的資料即使符合條件也不會寄送通知。

2. 編輯多版本表單的資料時，會因為該張表單上沒有另一個有設定共通篩選通知我的多版本表單所設定的篩選欄位而無法觸發發送通知。

例如：報價單有 A、B 兩種多版本表單，在 A 版本的報價單設有針對「總金額」欄位的共通篩選以及通知，但 B 表單中沒有「總金額」的欄位。因此在編輯儲存 B 表單時因為沒有該欄位，則該欄位會被視為空值，不滿足通知條件，便不會發送共通篩選通知。

在表單的工具選單中的同步與通知選擇通知設定。

可以針對該表單設定通知，例如只要該表單有新增或修改資料時便發送通知，或是只有與你相關的資料修改或新增回應時發送通知。

備註：跟我相關的資料包含：我新增的資料、被指派給我的資料、我回應過的資料。
