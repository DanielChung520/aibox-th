## 表單資料回應

團隊可以對話的其他方法

在 Ragic 上，你可以針對每一筆資料做留言回應，這樣的功能讓使用者們能夠溝通、討論。

在表單頁右下方的工具列中點擊對話框的圖示，點開來後就能回應以及看到其他人的留言。

在留言回應工具中，可以上傳任何格式的檔案作為附件，也可以使用 BBCodes 。

如果公司設定有啟用回應區 Markdown 排版，就可以使用 Markdown 語法來排版內容，例如粗體、清單、引用等，讓文字更容易閱讀。詳細說明請參考 Markdown 欄位說明。

你可以點擊附加檔案或是直接將檔案拖曳到回應框中來上傳附件。

注意：一則回應只能上傳一個附件。

將滑鼠移到回應的右上角點選「X」符號即可刪除該則回應，目前可以刪除回應的只有SYSAdmin (系統管理者)以及留言該則回應的使用者。

在表單頁瀏覽一筆資料時，可以針對任何一格欄位做回應或是加上註解。

在該欄位值的地方按右鍵，選擇加入註解

當你新增註解並儲存後，儲存格右上方就會有個紅色的三角形。

只要把游標移到這個三角形上，就會顯示註解，其他使用者可以看到別人下的註解，也可以新增回覆。

在表單中除了使用回應留言、加上註解以及 @ 提及的功能，也可以參考以下方法來增加團隊溝通的效率。

如果表單設計中有設計子表格來讓你們做留言回應的話，也是很方便的方法！因為子表格可以存放多筆資料，用來當做團隊間留言對話的地方也是非常方便的一個選擇！

你也可以利用通知設定，在其他使用者新增或修改一筆跟你有關的資料時通知你。
