## BBCodes 產生器

BBCodes 產生器

插入 Font Awesome 圖示

在表單中，可以使用在論壇或是電子佈告欄系統常用到的 BBCode tags。當你在填寫欄位種類為自由輸入等「純文字欄位」以及「留言回應」做內部溝通時，使用 BBCode tags 非常地方便。

除了在填寫欄位值可以利用 BBCode 以外，表單設計也可以利用靜態文字欄位插入 BBCode，像是需要在表單放上公司 Logo 圖片作為固定的設計樣式。

在欄位或回應中輸入「/」，會自動跳出 BBCodes 選單，就可以直接從中選擇需要的 tag 囉！

框選欄位文字時，也會出現 BBCodes 選單。

以下介紹目前支援的 tags，以及其呈現方式。

備註：一般建議由系統管理者將此 BBCode 用於敘述欄位，套用於敘述欄位時只能做為顯示用途，計算結果不會被存入資料庫。

可以使用 BBCode 來改變文字的格式與顏色，請參考下表。

備註：設定圖片的長跟寬時，如果圖片來源大小不一的時候會導致圖片變形，這時可以只設定長或寬，例如： [img=100x] 或 [img=x20]，來分別固定寬度 100 等比例縮放或是固定高度 20 來等比例縮放圖片。

另外要注意的是，如果你是要用插入圖片的 BBCode，圖片網址要是有效的網址，無論是上傳到其他網路空間或是 Ragic 的圖片網址，也就是打開後直接是圖片或是下載圖片的網址。

你可以在表單資料回應上傳公司的 Logo 圖片檔，並透過自己的滑鼠右鍵來取得它的網址。

你可以利用[fa=type] BBCode 來插入 Font Awesome 的圖示，「type」與各自對應 Font Awesome 的圖示以及實際使用範例請參考下表：

注意：由於 Font Awesome 會一直釋出新的圖示，Ragic 並不支援 Font Awesome 所列出的所有圖示。

想要在欄位中以地圖的方式呈現地址的話，可以輸入地址至[addr] BBCode 中。

範例：[addr]New York, New York[/addr]

可以利用[embed] BBCode來嵌入影片，嵌入的影片網址要帶有嵌入參數，參考以下範例。

範例：[embed]https://www.youtube.com/embed/UOhNHDBfsi4?si=EcrKIT7fm5j5Gbua[/embed]

有需要的話，也可以在嵌入影片的 BBCode 加入寬＊高來設定大小：[embed=800x600]video_url[/embed]

利用 BBCode:[mailto] 來發送信件至設定的信箱。

利用 BBCode:[tel] 來撥號至指定號碼。

利用 BBCode:[sms] 來發送簡訊至指定號碼。

可以嵌入外部網頁的資源，像是公司網站的頁面、自行開發的報表、 Google Calendar 或 Youtube 影片等。

BBCode：[iframe=width x height]嵌入的網址[/iframe]

Tips：如果嵌入到 Ragic 的 iframe 內容被阻擋（例如顯示「此內容已被封鎖」），請至公司設定 → 帳號設定對「iframe sources」進行設定、調整。

利用 [poll] BBCode 來建立投票活動，讓資料庫中的使用者一起票選出最佳方案。

注意：資料庫中所有相同的「投票名稱」都會呼叫同一個投票活動，如果想建立新的投票請用不同的投票名稱。如果原有的投票已被刪除，就可以使用之前的名稱。

在欄位中輸入[poll]此投票的名稱[/poll]。
