## 請針對上方勾選項目提供詳細說明：

如果你在表單中沒有看到以下介紹的功能，這可能跟你擁有的權限有關。如有任何關於分享表單權限上的問題，請聯絡你們的系統管理者進行進一步的確認或是調整權限設定。

如果需要分享表單或是內嵌填寫表單的網址給外部的人員，例如：客戶訂購單、活動報名表、問卷調查或顧客意見回饋，可以在列表頁或表單頁上方點選工具，並選擇分享這張表單。

便可以複製網址或提供QR Code 給目標使用者填寫或閱覽這張表單。

請先確認表單的存取權限是否有針對目標使用者設定正確的權限。

1. 填寫表單用網址：使用者看到的填寫介面會類似 Google 問卷，這是用 Ragic 網頁內嵌工具產出的網址，可透過「設定」來調整問卷的外觀

注意：系統管理者需要在功能權限開放產生網站內嵌元件權限才可以進入「設定」頁面。

2. 分享原始網址：直接將這張表單的網址分享，讓有權限的使用者直接進入這張表單填寫或閱覽。
