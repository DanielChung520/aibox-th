# 技能 01 — 登入與首頁

## 功能概述

本系統支援 JWT 登入驗證，支援「記住用戶名」功能。登入後自動最大化視窗（僅 Tauri 桌面環境），並根據主題設定載入亮色或暗色介面。

**重要澄清**：首頁（`/app/home`）並非儀表板，僅顯示系統 Logo，是最簡化的首頁形態。

## 功能地圖

| 頁面 | 路由 | 說明 |
|------|------|------|
| 登入頁 | `/login` | 用戶認證 |
| 歡迎頁 | `/` | 3秒自動跳轉 |
| 首頁 | `/app/home` | 僅顯示 EDGE Logo |

---

## 1. 登入頁（Login）

### 路由
`/login`

### 前置條件
- 系統已啟動（Rust API Gateway + 前端 Dev Server）
- 有效的用戶帳戶

### 操作步驟

**Step 1. 開啟系統**
在瀏覽器訪問 `http://localhost:1420`，或直接開啟 Tauri 桌面應用。

**Step 2. 輸入帳戶資訊**
- **用戶名**（必填）：輸入已註冊的用戶名
- **密碼**（必填）：輸入對應密碼
- **記住用戶名**（選填）：勾選後下次開啟自動帶入用戶名

**Step 3. 點擊登入**
點擊「**登入**」按鈕，系統進行驗證。

**Step 4. 驗證成功**
- 出現「登入成功」提示
- 視窗自動最大化（Tauri 桌面環境）
- 3秒後自動跳轉至首頁 `/app/home`

**Step 5. 驗證失敗**
- 顯示錯誤提示（紅色訊息）
- 停留在登入頁，可重新輸入

### 預設帳戶

| 用戶名 | 密碼 | 角色 |
|--------|------|------|
| admin | admin123 | 系統管理員 |

### 介面元素

| 元素 | 說明 |
|------|------|
| Logo | 右上角 EDGE 標誌，隨主題變化（亮/暗） |
| 用戶名輸入框 | 支援貼上，左側有用戶圖示 |
| 密碼輸入框 | 隱藏顯示切換，左側有鎖頭圖示 |
| 記住用戶名 | Checkbox，預設不勾選 |
| 登入按鈕 | 主色按鈕，點選後顯示 loading 狀態 |

### 常見問題

**Q: 登入後一直停留在歡迎頁？**
> 檢查瀏覽器主控台（DevTools → Console）是否有 JWT token 解析錯誤。確認 API Gateway（port 6500）正常運作。

**Q: 視窗未自動最大化？**
> 僅在 Tauri 桌面環境下生效，瀏覽器模式不會自動最大化。

## 2. 歡迎頁（Welcome）

### 路由
`/`（根路徑）

### 操作步驟
- 系統根據是否已登入自動跳轉：
  - **已登入**：3秒後自動跳轉至 `/app/home`
  - **未登入**：3秒後自動跳轉至 `/login`

### 介面元素

| 元素 | 說明 |
|------|------|
| EDGE Logo 動畫 | 中央大型 Logo，帶動畫效果 |
| 版本號 | 底部顯示 `v1.0.0` |
| 進度條 | Logo 下方，3秒倒數進度 |

---

## 3. 首頁（Home）

### 路由
`/app/home`

### 前置條件
- 已登入系統

### 實際介面說明

**重要澄清**：首頁並非個人化儀表板或功能入口，僅顯示一個**置中的 EDGE Logo**，周圍為空白區域。

點擊左側側邊欄的「首頁」圖示，進入此頁面後，看到的只有一個大型 Logo 置於頁面中央，無任何快捷功能卡片或系統狀態資訊。

### 介面元素

| 元素 | 說明 |
|------|------|
| EDGE Logo | 置中顯示，無其他內容 |
| 版本號 | 左下角顯示 `v1.0.0` |
| 服務狀態圖示 | 右上角雲朵按鈕，滑鼠移入顯示服務狀態 |
| 主題切換 | 右上角太陽/月亮按鈕，切換亮/暗主題 |
| 用戶資訊 | 右上角，顯示當前登入用戶名與角色 |

### 主題切換
- 點選右上角「**☀️ 太陽**」：切換至亮色主題
- 點選右上角「**🌙 月亮**」：切換至暗色主題
- 主題設定會保存在瀏覽器 localStorage

### 常見問題

**Q: 首頁只有 Logo，沒有任何功能入口？**
> 這是目前的預設設計。左側側邊欄是主要導航功能表的入口，包括：任務對話、AI 代理、知識管理、資料代理、系統管理等分類。

**Q: 點擊 Logo 會發生什麼？**
> 點擊 Logo 無任何反應，不會導航。
