# 技能 04 — 資料代理

## 功能概述

資料代理模組提供三大功能：**Schema 管理**（Ragic 資料表結構檢視）、**NL→Ragic 查詢**（自然語言查詢）和**資料湖瀏覽**（資料表預覽）。所有功能均基於後端 Data Agent 服務（port 8003）。

## 功能地圖

| 頁面 | 路由 | 說明 |
|------|------|------|
| Schema | `/app/data-agent/schema` | 262 張 Ragic 資料表，分類檢視 |
| NL→Ragic 查詢 | `/app/data-agent/playground` | 自然語言查詢，結果/意圖/參數/偵錯分頁 |
| 資料湖 | `/app/data-agent/datalake` | 左側表格清單，右側欄位結構+資料預覽 |

## 1. Schema 管理（SchemaPage）

### 路由
`/app/data-agent/schema`

### 前置條件
- 已登入系統
- Data Agent 服務正常運作（port 8003）

### 操作步驟

**Step 1. 進入 Schema 頁**
點擊左側側邊欄「**資料代理**」→「**Schema**」。

**Step 2. 瀏覽資料表列表**
- 頂部顯示有效/無效資料表統計
- 支援 Tab 分類篩選（基礎資料、進銷存、生產製造、CRM 等）
- 支援 Category 下拉選單精確篩選
- 搜尋框可依 Table ID 或表名過濾

**Step 3. 查看欄位**
- 點選該列的「**查看欄位**」按鈕
- 彈出 Modal 顯示該表的欄位列表（FieldInfo）

**Step 4. 預覽資料**
- 雙擊任意列，或點選「**查看資料**」按鈕
- 彈出 Modal 顯示資料預覽
- 支援切換 preview_mode（分頁/全部）

**Step 5. 編輯資料表**
- 點選「**edit**」按鈕
- 開啟編輯 Modal，可修改 table 名稱、模組、頁籤等資訊

**Step 6. 刪除資料表**
- 點選「**delete**」按鈕
- 確認後刪除

**Step 7. 匯入資料表**
- 點選頂部「**匯入**」按鈕或 SchemaImportSection 區塊
- 上傳後自動刷新列表

**Step 8. 設定**
- 點選右上角「**Setting**」按鈕
- 開啟 SchemaSettingsDrawer

### 介面元素

| 元素 | 說明 |
|------|------|
| 統計標籤 | 有效/無效資料表數量 |
| Tab 分類 | 依類型分類（基礎資料/進銷存/生產製造/CRM等） |
| Category 下拉 | 精確分類篩選 |
| 搜尋框 | Table ID 或表名關鍵字過濾 |
| 查看欄位按鈕 | 開啟欄位 Modal |
| 查看資料按鈕 | 開啟資料預覽 Modal |
| edit 按鈕 | 編輯資料表資訊 |
| delete 按鈕 | 刪除資料表 |
| 匯入按鈕 | 匯入新資料表 |
| Setting 按鈕 | 開啟設定面板 |
| SchemaColumnsModal | 欄位列表 Modal |
| SchemaDataPreviewModal | 資料預覽 Modal，含分頁/全部切換 |

### 常見問題

**Q: 為什麼有 262 張資料表？**
> 這些是 Ragic 系統中的業務資料表，涵蓋採購、庫存、生產、銷售、財務等模組，供 NL→SQL 查詢使用。

## 2. NL→Ragic 查詢（QueryPlayground）

### 路由
`/app/data-agent/playground`

### 前置條件
- 已登入系統
- Data Agent 服務正常運作

### 操作步驟

**Step 1. 進入查詢工作台**
點擊左側側邊欄「**資料代理**」→「**NL 查詢**」。

**Step 2. 輸入自然語言查詢**
- 在文字輸入框輸入查詢意圖（如：「查詢本月採購金額超過 100 萬的供應商」）
- 按 `Enter` 執行（`Shift+Enter` 換行）
- 或點選「**Execute**」按鈕

**Step 3. 檢視查詢結果**
- **成功**：
  - 顯示「查詢結果」Card
  - 分為四個 Tab：
    - **result**：結果表格（動態欄位，含分頁）
    - **intent**：意圖匹配（intent_id、score、信賴度標籤）
    - **params**：翻譯後參數（where 條件、limit、offset）
    - **debug**：偵錯資訊（response code、connection name、table_key、path_used、raw_error）
  - 右側統計面板：執行時間、結果筆數、預估 token

- **需要澄清**：
  - 顯示 warning Alert，附帶可點選的建議標籤（Tag.CheckableTag）
  - 點選建議直接執行該查詢

- **錯誤**：
  - 顯示 error Alert
  - 可展開查看 raw_error 詳情

**Step 4. 使用快捷範本**
- 預設快捷範本 Tags，點選後自動填入並執行

**Step 5. 清除**
- 點選「**Clear**」按鈕清除輸入與結果

### NL→Ragic 翻譯流程

```
自然語言 → Data Agent → 意圖匹配 → NL→SQL 翻譯 → Ragic API → 結果
                              ↓
                      path_a (Tool-Calling) 或 path_b (Pandas aggregate)
```

### 介面元素

| 元素 | 說明 |
|------|------|
| 自然語言輸入框 | TextArea，支援 Enter 執行、Shift+Enter 換行 |
| Execute 按鈕 | 執行查詢（PlayCircleOutlined） |
| Clear 按鈕 | 清除輸入與結果（ClearOutlined） |
| 快捷範本 Tags | 點選自動填入並執行 |
| 結果狀態 Tag | success/error/clarification_needed |
| 四個結果 Tab | result / intent / params / debug |
| 意圖 Tab | intent_id、score（分為高/中/低三級信賴度） |
| 參數 Tab | translated_params.where 條件、limit、offset |
| 偵錯 Tab | path_used（彩色 Tag）、field_labels、raw_error |
| 統計面板 | execution_time_ms、record_count、estimated_tokens |

### 常見問題

**Q: 查詢結果顯示 clarification_needed？**
> 系統無法明確理解您的查詢意圖，請嘗試使用更具體的描述，或點選系統提供的建議 Tags。

**Q: 路徑顯示 path_a 和 path_b 有何不同？**
> path_a 為 Tool-Calling 方式（呼叫外部工具）；path_b 為 Pandas aggregate 方式（本地資料聚合）。系統自動選擇合適路徑。

**Q: debug 中的 field_labels 是什麼？**
> 欄位標籤映射，顯示 NL 查詢中翻譯的欄位名稱與原始 Table ID 的對應關係。

## 3. 資料湖（DataLakePage）

### 路由
`/app/data-agent/datalake`

### 前置條件
- 已登入系統
- Data Agent 服務正常運作

### 操作步驟

**Step 1. 進入資料湖頁**
點擊左側側邊欄「**資料代理**」→「**資料湖**」。

**Step 2. 瀏覽資料表清單（左欄）**
- 以清單形式顯示所有可用資料表
- 每筆記錄顯示：表名、模組標籤、來源標籤、Table ID
- 灰色表示已停用的資料表

**Step 3. 篩選**
- 「**全部/已啟用**」Switch：切換顯示全部或僅顯示已啟用
- 搜尋框：依表名、模組、Table ID 關鍵字過濾

**Step 4. 點選資料表**
- 點選任一資料表名稱
- 右側載入該表的詳細資訊

**Step 5. 檢視資料表資訊（右欄）**
- **Description 面板**：
  - 表名、Table ID（代碼）、模組、來源、狀態、Sheet Key
  - 如有 Ragic 表單連結，點選可開新分頁
- **Tab：Schema**
  - 欄位結構表格（欄位名、類型、可寫入、備註）
  - Tag 顯示欄位總數
- **Tab：Data**
  - 資料預覽表格，含分頁（每頁 20 筆）
  - 顯示目前可見範圍與總筆數

**Step 6. 分頁瀏覽**
- 切換頁碼，載入更多資料

**Step 7. 重試**
- 如載入失敗，Alert 區域有「**重試**」Tag

### 介面元素

| 元素 | 說明 |
|------|------|
| 全部/已啟用 Switch | 切換顯示全部或僅已啟用資料表 |
| 搜尋框 | 表名/模組/Table ID 關鍵字過濾 |
| 資料表清單 | 左欄，滾動檢視 |
| Table ID 標籤 | 綠色 Tag 顯示來源（ragic） |
| 停用標籤 | 灰色 Tag，status='disabled' |
| 模組彩色標籤 | 不同模組有不同顏色 |
| 表單連結 | Description 中的超連結，開啟 Ragic |
| Schema Tab | 欄位結構（欄位名、類型、可寫入、備註） |
| Data Tab | 資料預覽，含分頁 |
| 重試 Tag | 載入失敗時出現 |

### 常見問題

**Q: 點選資料表後右側一片空白？**
> 可能是網路問題或 Data Agent 服務異常，嘗試點選「重試」Tag。

**Q: 表單連結無法開啟？**
> 確認 Ragic 系統正常運行，且該表已配置 sheet_url。
