# 技能 02 — AI 任務對話

## 功能概述

AI 任務對話是系統的核心功能，基於 SSE（Server-Sent Events）串流技術，提供即時的 AI 回應。支援多 Provider 切換（Ollama、LM Studio）、對話歷史管理、檔案上傳功能。歷史記錄頁支援單筆及批次刪除。排程任務頁目前為佔位畫面（功能開發中）。

## 功能地圖

| 頁面 | 路由 | 說明 |
|------|------|------|
| AI 對話 | `/app/task-session/chat` | SSE 串流聊天 + 檔案上傳 |
| 歷史記錄 | `/app/task-session/history` | 對話歷史，支援單筆/批次刪除 |
| 排程任務 | `/app/task-session/scheduled` | 顯示「功能開發中」 |

## 1. AI 對話（TaskSessionChat）

### 路由
`/app/task-session/chat` 或 `/app/task-session/chat/:sessionKey`

### 前置條件
- 已登入系統
- 至少有一個 AI Provider 正常運作（Ollama port 11434 / LM Studio port 1234）

### 操作步驟

**Step 1. 進入 AI 對話頁**
點擊左側側邊欄「**任務對話**」→「**對話**」。

**Step 2. 選擇 AI 模型 Provider**
- 點選聊天輸入框左側的「**Provider 下拉選單**」
- 選擇要使用的 AI 模型（如 `ollama` / `lm-studio`）
- 模型會自動帶入該 Provider 的預設模型
- Provider 停用（`status !== 'enabled'`）或無 API Key（非本地 Provider）時會被禁用

**Step 3. 輸入訊息**
- 在底部輸入框輸入訊息（支援 Markdown）
- 按 `Enter` 鍵直接發送，`Shift+Enter` 換行
- 點擊「**送出**」按鈕發送

**Step 4. 接收 AI 回應**
- AI 回應以 SSE 串流方式即時顯示
- 訊息下方會出現工具列按鈕（附件、音訊、表情、送出）

**Step 5. 檔案上傳**
- 點擊「**附件**」按鈕（PaperClipOutlined）上傳檔案
- 檔案上傳狀態透過 SSE 即時更新
- 上傳完成後可刪除檔案

**Step 6. 開始新對話**
- 點擊「**+**」按鈕可清除當前對話，開始新 session

### 介面元素

| 元素 | 說明 |
|------|------|
| Provider 下拉選單 | 選擇 AI 模型供應商，顯示 provider 名稱 |
| 模型名稱 | 當前使用的模型名稱（如 llama3.2） |
| 聊天訊息區 | 訊息氣泡（使用者訊息靠右，AI 回覆靠左） |
| 輸入框 | 支援 Markdown，右側有工具列按鈕 |
| 工具列按鈕 | 附件(PaperClipOutlined)、表情(SmileOutlined)、送出(SendOutlined) |
| 新對話按鈕 | 左上角「+」按鈕，開始新 session |
| 訊息操作 | 每則訊息旁有編輯、刪除圖示（EditOutlined, DeleteOutlined） |

### 訊息氣泡功能

| 功能 | 說明 |
|------|------|
| 編輯訊息 | 點選訊息旁「✏️」圖示可重新編輯並重新送出 |
| 刪除訊息 | 點選訊息旁「🗑️」圖示可刪除該訊息 |

### 常見問題

**Q: 送出訊息後遲遲無回應？**
> 1. **Model 配置錯誤**：確認系統參數中 `task_chat.default_model` 是否為聊天模型（如 `llama3.2:latest`），而非 embedding 模型（如 `bge-m3:latest`）。
> 2. **Provider 未啟動**：確認 Ollama（port 11434）或 LM Studio（port 1234）正常運作。

**Q: 無法選擇特定模型？**
> 檢查該模型的 `status` 是否為 `enabled`。disabled 的模型不會出現在下拉選單中。

**Q: Provider 顯示為禁用狀態？**
> 非本地 Provider（不包含 localhost/127.0.0.1）需要填寫 API Key 才會啟用。本地 Provider 預設啟用。

## 2. 歷史記錄（TaskSessionHistory）

### 路由
`/app/task-session/history`

### 前置條件
- 已登入系統

### 操作步驟

**Step 1. 進入歷史記錄頁**
點擊左側側邊欄「**任務對話**」→「**歷史記錄**」。

**Step 2. 瀏覽對話歷史**
- 以列表形式展示所有過往對話 session
- 每筆記錄顯示：標題（無標題則顯示「無標題」）、最後更新時間、使用的 Provider 與 Model
- 按時間排序，最新在上

**Step 3. 點選進入歷史對話**
- 點選任一歷史記錄，自動跳轉至 `/app/task-session/chat/:sessionKey`
- 可繼續該對話

**Step 4. 刪除歷史記錄**

**單筆刪除**：
- 點選該筆記錄右上角的「刪除」圖示（DeleteOutlined）
- 確認後刪除該 session

**批次刪除**：
- 點擊列表上方的「**選擇**」按鈕進入選擇模式
- 勾選要刪除的筆記錄（每筆記錄前出現 Checkbox）
- 點擊「**刪除**」按鈕
- 確認後批次刪除所選 sessions

**Step 5. 退出選擇模式**
- 點擊「**取消**」按鈕退出選擇模式

### 介面元素

| 元素 | 說明 |
|------|------|
| 選擇按鈕 | 進入/退出批次選擇模式 |
| 刪除按鈕 | 選擇模式下刪除所選 sessions |
| 歷史列表 | 顯示 session 標題、更新時間、Provider、Model |
| 刪除圖示 | 單筆刪除（StopOutlined 圖示） |
| Checkbox | 選擇模式下勾選特定記錄 |
| 空狀態 | 無歷史記錄時顯示 Empty 元件 |

### 常見問題

**Q: 刪除後能否恢復？**
> 不能。刪除操作為永久性，無法復原。
