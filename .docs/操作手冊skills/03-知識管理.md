# 技能 03 — 知識管理

## 功能概述

知識管理模組提供三大功能：**知識本體（Ontology）**、**知識庫（Knowledge Base）**與 **RAG 檢索**。知識本體用於定義和管理領域概念模型（Domain/Major 階層）；知識庫用於存放可供 AI 檢索的文件知識，支援向量化和圖譜抽取；兩者皆支援向量檢索。

## 功能地圖

| 頁面 | 路由 | 說明 |
|------|------|------|
| 知識本體 | `/app/knowledge/ontology` | Domain/Major 階層本體，支援匯入/圖譜 |
| 知識庫管理 | `/app/knowledge/management` | 知識庫列表，網格/表格檢視 |
| 知識庫詳情 | `/app/knowledge/management/:id` | 三欄佈局：檔案列表 / 內容圖譜 / 節點關係 |

## 1. 知識本體（OntologyList）

### 路由
`/app/knowledge/ontology`

### 前置條件
- 已登入系統
- Knowledge Agent 服務正常運作（port 8007）

### 操作步驟

**Step 1. 進入知識本體頁**
點擊左側側邊欄「**知識管理**」→「**本體**」。

**Step 2. 瀏覽本體列表**
- 查看所有已建立的知識領域本體（Domain 層級）
- 每筆記錄顯示：名稱、說明、版本、標籤、實體數、關係數
- 支援「**Expand**」展開按鈕，展開後顯示該 Domain 下的 Major 本體

**Step 3. 搜尋本體**
- 在頂部搜尋框輸入關鍵字，過濾本體列表

**Step 4. 檢視圖譜**
- 點選「**圖譜視圖**」按鈕，開啟預覽 Modal
- Modal 包含：
  - 本體描述資訊（名稱、顯示名稱、類型標籤、版本、作者、實體數、關係數）
  - Tab 切換：Entities（實體列表）、Properties（關係列表）
  - 互動式 OntologyGraphViewer 圖譜元件

**Step 5. Basic 5W1H 設定**
- 點選「**Basic 5W1H 設定**」按鈕，開啟 Modal
- 用於定義 NER/RE/RT pipeline 的基礎維度（Who/What/When/Where/Why/How）
- 可新增/刪除維度列，編輯維度標籤與 extractionIntent

**Step 6. 匯入本體**

**匯入 Domain**：
- 點選「**匯入 Domain**」按鈕
- 上傳 JSON 檔案（拖曳或點選上傳）
- 系統解析後顯示預覽，確認後提交

**匯入 Major**（需先展開某個 Domain）：
- 點選目標 Domain 旁的「**匯入 Major**」
- 流程同匯入 Domain，但會自動帶入 domain 資訊

**Step 7. 刪除本體**
- 點選「**刪除**」按鈕（Popconfirm 二次確認）

### 介面元素

| 元素 | 說明 |
|------|------|
| 搜尋框 | 過濾本體列表 |
| Basic 5W1H 設定按鈕 | 開啟 5W1H 編輯 Modal |
| 匯入 Domain 按鈕 | 匯入完整知識領域本體（JSON） |
| 圖譜視圖按鈕 | 開啟本體視覺化預覽 Modal（每列均有） |
| Expand 展開按鈕 | 展開後顯示該 Domain 下的 Major 本體列表 |
| 匯入 Major 按鈕 | 僅在展開列中出現，匯入主要實體 |
| 刪除按鈕 | 刪除該本體（Popconfirm 確認） |
| 圖譜預覽 Modal | 大型 Modal，含描述、Entities/Properties Tab、圖譜 Viewer |
| 分頁控制 | 表格底部分頁（上一頁/下一頁、頁碼、每頁筆數） |

### 常見問題

**Q: 匯入本體失敗？**
> 檢查上傳的本體檔案格式是否正確（需包含 `entity_classes` 與 `object_properties` 陣列）。確認 Knowledge Agent 服務正常。

**Q: 圖譜視圖空白？**
> 該本體可能沒有實體或關係資料。確認本體已正確建立並包含實體/關係定義。

## 2. 知識庫管理（KnowledgeBaseManagement）

### 路由
`/app/knowledge/management`

### 前置條件
- 已登入系統
- Knowledge Agent 服務正常運作

### 操作步驟

**Step 1. 進入知識庫管理頁**
點擊左側側邊欄「**知識管理**」→「**知識庫**」。

**Step 2. 瀏覽知識庫列表**
- 支援**網格檢視**（KBCardGrid）和**表格檢視**（KBTableList）切換
- 每筆記錄顯示：名稱、描述、標籤、網域/主要本體

**Step 3. 搜尋與篩選**
- 頂部搜尋框關鍵字過濾
- 「我的收藏」Switch：僅顯示已收藏的知識庫

**Step 4. 建立新知識庫**
- 點選「**建立知識庫**」按鈕
- 填寫表單：名稱、描述、標籤（Select mode=tags）、Ontology Domain、Ontology Majors（多選）
- 確認後建立

**Step 5. 進入知識庫詳情**
- 點選任一知識庫名稱，進入詳情頁 `/app/knowledge/management/:id`

**Step 6. 編輯元資料**
- 點選知識庫的「編輯」按鈕
- 修改名稱、描述、標籤、領域、主要本體

**Step 7. 複製知識庫**
- 點選「複製」按鈕，整個知識庫（含檔案）複製一份

**Step 8. 刪除知識庫**
- 點選「刪除」按鈕，確認後刪除

**Step 9. 收藏切換**
- 點選「收藏」按鈕，切換收藏狀態

**Step 10. 授權管理**
- 點選「授權」按鈕，開啟授權 Modal
- 檢視目前繼承的角色，選擇額外授權角色（Select mode=multiple）

### 介面元素

| 元素 | 說明 |
|------|------|
| 搜尋框 | 關鍵字過濾 |
| 我的收藏 Switch | 僅顯示已收藏知識庫 |
| 檢視切換 | 網格/表格檢視 Radio |
| 建立知識庫按鈕 | 開啟建立 Modal |
| 編輯按鈕 | 進入詳情或修改元資料 |
| 複製按鈕 | 複製整個知識庫 |
| 刪除按鈕 | 刪除知識庫 |
| 收藏按鈕 | 切換收藏狀態（HeartOutlined） |
| 授權按鈕 | 開啟角色授權 Modal |
| 知識庫卡片 | 名稱、描述、標籤、網域資訊 |
| 授權 Modal | 顯示繼承角色標籤 + 額外角色多選 |

### 常見問題

**Q: 知識庫與本體有何關聯？**
> 知識庫建立時可指定 Ontology Domain 和 Major，決定該知識庫的文件會使用哪些本體進行關係抽取和向量化。

## 3. 知識庫詳情（KnowledgeBaseDetail）

### 路由
`/app/knowledge/management/:id`

### 前置條件
- 已有可訪問的知識庫
- 知識庫已上傳文件

### 實際佈局（三欄設計）

此頁面採用**三欄佈局**：
- **左欄**：檔案列表與上傳
- **中欄**：內容檢視器（原始內容 / 圖譜 / 向量）
- **右欄**：節點與關係面板（僅在圖譜 Tab 時顯示）

### 操作步驟

**Step 1. 進入知識庫詳情**
從知識庫管理頁點選任一知識庫進入。

**Step 2. 瀏覽檔案列表（左欄）**
- 查看該知識庫中所有已上傳的檔案
- 點選檔案名稱，在中欄顯示該檔案

**Step 3. 上傳檔案**
- 點選「**上傳**」區域或切換至上傳模式
- 支援 PDF、TXT、Markdown 等格式
- 上傳後系統自動進行向量化與圖譜抽取
- **注意**：處理狀態會在檔案列表中即時更新（polling 机制）

**Step 4. 刪除檔案**
- 點選檔案旁的刪除按鈕，確認後刪除

**Step 5. 檢視檔案內容（中欄）**
- **原始內容 Tab**：顯示檔案原文
- **圖譜 Tab**：顯示該檔案的知識圖譜（G6 互動式圖表）
- **向量 Tab**：顯示向量檢索相關資訊
- 狀態顯示：`vector_status` 和 `graph_status`（pending/processing/queued/完成）

**Step 6. 節點與關係面板（右欄）**
- 當檢視圖譜 Tab 時，右欄顯示節點和關係列表
- 點選節點名稱，圖譜中對應節點會被選中（高亮）

**Step 7. 處理狀態監控**
- 當有任何檔案的 vector_status 或 graph_status 為 `pending/processing/queued` 時
- 頁面自動每 5 秒輪詢一次，直到所有處理完成
- 用戶無需手動刷新

### 向量化和圖譜抽取流程

```
檔案上傳 → pending → processing → queued → 完成
                ↓              ↓
           向量化完成      圖譜抽取完成
```

### 介面元素

| 元素 | 說明 |
|------|------|
| 返回按鈕 | 左上角返回箭頭，回到知識庫列表 |
| 檔案列表（左欄） | 顯示檔案名稱、狀態標籤 |
| 上傳區域 | 拖放或點選上傳檔案 |
| 刪除檔案 | 刪除該檔案 |
| 內容檢視器（中欄） | Tab：原始內容 / 圖譜 / 向量 |
| 處理狀態標籤 | vector_status、graph_status（顏色區分狀態） |
| 圖譜 Viewer | G6 互動式圖表，支援節點點選 |
| 節點關係面板（右欄） | 節點列表，點選高亮對應圖譜節點 |
| 設定按鈕 | 開啟 KBSettingsModal |
| 輪詢指示 | 處理中時右下角顯示 loading |

### 常見問題

**Q: 檔案上傳後一直顯示 processing？**
> 向量化或圖譜抽取可能需要較長時間。檢查 Knowledge Agent 服務（port 8007）是否正常運行。

**Q: 圖譜 Tab 為什麼沒有內容？**
> 該檔案的 graph_status 尚未完成抽取。等待 processing 完成後即可檢視。

**Q: 為什麼要輪詢？**
> 後端的向量化和圖譜抽取為非同步任務，頁面透過 5 秒輪詢追蹤處理狀態，確保使用者看到最新狀態。
