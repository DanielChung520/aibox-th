# 技能 08 — 主題與模板

## 功能概述

主題模板模組用於管理 Shell（外殼主題）和 Content（內容主題）的 Theme Template。支援建立、編輯、刪除、啟用模板，以及透過 Token 編輯器客製化各類設計 token。

## 功能地圖

| 頁面 | 路由 | 說明 |
|------|------|------|
| 主題模板 | `/app/theme-template` | Shell/Content 模板 CRUD，Token 編輯 |

## 主題模板（ThemeTemplateManagement）

### 路由
`/app/theme-template`

### 前置條件
- 已登入系統
- 具有系統管理員角色

### 操作步驟

**Step 1. 進入主題模板頁**
點擊左側側邊欄「**系統管理**」→「**主題模板**」。

**Step 2. 瀏覽模板列表**
- 頁面包含兩張表格：**Shell 模板** 和 **Content 模板**
- 每筆記錄顯示：名稱、描述、是否為預設（is_default Tag）、狀態（enabled/disabled）、建立時間

**Step 3. 新增模板**
- 點選「**新增模板**」按鈕（Shell 或 Content 表格里）
- 填寫表單：
  - **名稱**（必填）
  - **描述**（TextArea）
  - **模板類型**（Select）：Shell / Content
  - **Tokens**：使用 `ShellTokensForm` 或 `ContentTokensForm` 編輯器編輯（視 template_type 而定）
  - **是否為預設**（Switch）：設定為系統預設模板
  - **狀態**（Select）：enabled / disabled
- 點選「**確認**」建立

**Step 4. 編輯模板**
- 點選「**編輯**」按鈕
- 開啟編輯 Modal，預填當前值
- 可修改 tokens（使用對應的 Form 編輯器）
- 點選「**確認**」儲存

**Step 5. 刪除模板**
- 點選「**刪除**」按鈕
- **is_default = true 的模板不可刪除**（刪除按鈕 disabled）
- Popconfirm 確認後刪除

**Step 6. 啟用模板**
- 點選「**啟用**」按鈕（Activate）
- 呼叫 `themeTemplateApi.activate(key)`
- 成功後呼叫 `reloadTemplates()`（Context helper）重新載入模板

### Token 編輯器

**ShellTokensForm** 和 **ContentTokensForm** 是專用元件，用於編輯各類設計 token：

- Shell tokens：可能包含外殼相關的顏色、間距、字體等
- Content tokens：可能包含內容區域的配色、邊框、陰影等

編輯時，Tokens 以結構化表單呈現，而非原始 JSON。

### 介面元素

| 元素 | 說明 |
|------|------|
| Shell 模板表格 | 顯示所有 Shell 模板 |
| Content 模板表格 | 顯示所有 Content 模板 |
| 新增模板按鈕 | 分別存在於兩個表格區塊 |
| 編輯按鈕 | 開啟編輯 Modal |
| 刪除按鈕 | 刪除模板（is_default 模板禁用） |
| 啟用按鈕 | 啟用該模板（ActivateOutlined） |
| is_default Tag | 藍色 Tag，標示預設模板 |
| 狀態 Tag | 綠色=啟用，灰色=停用 |
| Token 編輯器 | ShellTokensForm / ContentTokensForm 元件 |
| 新增/編輯 Modal | 寬度 900，含 tokens 編輯區 |

### 常見問題

**Q: 為什麼不能刪除 is_default 的模板？**
> 預設模板是系統的設計基準，刪除可能導致 UI 無法正常渲染，因此禁止刪除。

**Q: 啟用模板後需要刷新嗎？**
> 不需要，系統會自動呼叫 `reloadTemplates()` 重新載入主題，UI 即時更新。

**Q: Shell 和 Content 模板有何不同？**
> Shell 模板控制外殼（如側邊欄、頂部導航），Content 模板控制內容區（如表格、表單）。兩者共同構成完整的主題系統。
