# 技能 07 — 浮動助手設定

## 功能概述

浮動助手設定用於配置「艾企」浮動助手的視覺樣式與對話行為。支援大量視覺 token（顏色、尺寸，毛玻璃效果、陰影、漸層等）的即時調整，並可選擇聊天模型。所有設定儲存至系統參數（`floating_assistant.*`），並即時套用至 DOM（CSS 變數）。

## 功能地圖

| 頁面 | 路由 | 說明 |
|------|------|------|
| 浮動助手設定 | `/app/floating-assistant-settings` | 浮動助手樣式與聊天模型設定 |

## 浮動助手設定（FloatingAssistantSettings）

### 路由
`/app/floating-assistant-settings`

### 前置條件
- 已登入系統
- 具有系統管理員角色（多數參數為系統級配置）

### 操作步驟

**Step 1. 進入浮動助手設定頁**
點擊左側側邊欄「**系統管理**」→「**浮動助手設定**」。

**Step 2. 啟用/停用浮動助手**
- 頂部「**啟用開關**」（Switch）
- 關閉後浮動助手不出現

**Step 3. 選擇聊天模型**
- 從下拉選單選擇模型
- 選項來自 `modelProviderApi.list()` 取得的 providers
- 設定寫入 `floating_assistant.chatModel` 參數

**Step 4. 調整尺寸與圓角**
- **modalWidth**：對話框寬度（Slider + InputNumber）
- **modalHeight**：對話框高度（Slider + InputNumber）
- **borderRadius**：圓角大小（Slider + InputNumber）

**Step 5. 調整毛玻璃效果**
- **blurIntensity**：模糊強度（Slider）
- **glassOpacity**：玻璃透明度（Slider）
- **saturation**：飽和度（Slider）

**Step 6. 設定顏色**
所有顏色透過 Ant Design ColorPicker 選擇（format='rgb'，showText 顯示色值）：

| 顏色分類 | 參數 key | 說明 |
|----------|----------|------|
| 對話框背景 | modalBg | 主背景色 |
| 標題列 | headerBg、headerBorderColor、titleColor、closeBtnColor | 標題列背景/邊框/文字/關閉按鈕 |
| 主體區 | bodyBg | 訊息區背景 |
| 頁腳區 | footerBg、footerBorderColor | 頁腳背景/邊框 |
| 輸入框 | inputBg、inputTextColor、inputBorderColor、inputPlaceholderColor | 輸入框各狀態顏色 |
| 送出按鈕 | sendBtnBg、sendBtnColor | 送出按鈕背景/文字 |
| AI 氣泡 | bubbleAiBg、bubbleAiTextColor | AI 訊息氣泡 |
| 使用者氣泡 | bubbleUserBg、bubbleUserTextColor | 使用者訊息氣泡 |
| 按鈕樣式 | buttonBg、buttonIconColor、buttonShadowColor、buttonPulseColor | 按鈕各狀態 |
| 陰影 | shadowColor、shadowInnerColor、resizeHandleColor | 陰影與調整把手 |
| 漸層 | gradientStart、gradientRadial1、gradientRadial2 | 漸層設定 |
| Mermaid/MD | mermaidBg、mermaidTextColor、linkColor、quoteBorderColor | Mermaid 圖與 Markdown 語法色 |
| 警告色 | warningColorDark、warningColorLight | 警告訊息色 |

**Step 7. 即時預覽**
- 所有變更**即時套用**至 DOM（CSS 變數 `--fa-*`）
- 無需等待，可直接看到效果

**Step 8. 保存設定**
- 點選「**保存**」按鈕
- 系統以 `Promise.all` 批次寫入所有參數：
  - `paramsApi.update('floating_assistant.<key>', value)`
- 成功後顯示訊息
- 同時 dispatch 全域 CustomEvent `floating-assistant-config-update`

**Step 9. 重置**
- 點選「**重置**」按鈕
- 回復至 `defaultConfig` 的預設值
- CSS 變數同步更新

### CSS 變數映射（部分）

| CSS 變數 | 對應設定 |
|----------|----------|
| `--fa-modal-width` | modalWidth |
| `--fa-body-bg` | modalBg |
| `--fa-gradient-start` | gradientStart |
| `--fa-bubble-ai-bg` | bubbleAiBg |
| `--fa-bubble-user-bg` | bubbleUserBg |

### 介面元素

| 元素 | 說明 |
|------|------|
| 啟用開關 | Switch，控制浮動助手是否顯示 |
| 聊天模型 Select | 從 providers 清單中選擇 |
| Slider + InputNumber | 尺寸/圓角/模糊等連續數值設定 |
| ColorPicker | 顏色選擇器，顯示 RGB 色值 |
| 保存按鈕 | 批次寫入所有參數（SaveOutlined） |
| 重置按鈕 | 回復預設值（ReloadOutlined） |

### 常見問題

**Q: 為什麼顏色修改後馬上就看到變化？**
> 系統使用 `document.documentElement.style.setProperty` 直接寫入 CSS 變數，無需刷新頁面。

**Q: 為什麼要用 Promise.all 儲存？**
> 避免多次 API 請求造成的 race condition，確保所有參數同時寫入。

**Q: CustomEvent 'floating-assistant-config-update' 是什麼？**
> 其他模組可以監聽此事件，在浮動助手設定變更時做出反應（如重新初始化對話狀態）。
