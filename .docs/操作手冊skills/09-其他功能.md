# 技能 09 — AI Agent 與工具瀏覽

## 功能概述

本模組包含兩個功能：**AI Agent 瀏覽**（BrowseAgent）和**工具瀏覽**（BrowseTools）。AI Agent 瀏覽展示 BPA（Business Process Automation）代理，以卡片形式呈現，支援收藏和啟動對話。工具瀏覽提供 MCP 工具的註冊管理，包括授權設置和 NL Intent 同步功能。

## 功能地圖

| 頁面 | 路由 | 說明 |
|------|------|------|
| AI Agent 瀏覽 | `/app/browse-agent` | BPA 代理卡片列表，含收藏/對話功能 |
| 工具瀏覽 | `/app/browse-tools` | 工具註冊管理，卡片/表格檢視，Admin 權限 |

## 1. AI Agent 瀏覽（BrowseAgent）

### 路由
`/app/browse-agent`

### 前置條件
- 已登入系統

### 操作步驟

**Step 1. 進入 AI Agent 瀏覽頁**
點擊左側側邊欄「**AI 代理與效率工具**」→「**AI 代理**」。

**Step 2. 瀏覽代理列表**
- 以卡片網格形式展示所有 BPA AI Agent
- 支援 Tab 分類：全部 / 進銷存 / 財務管理 / 企業戰略 / 行政助理 / Ragic 採購流程
- 每個代理卡片顯示：
  - 名稱、描述、狀態（在線/離線）
  - 使用次數統計
  - 操作按鈕

**Step 3. 搜尋與篩選**
- 搜尋框：依代理名稱或描述關鍵字過濾
- 「我的收藏」Switch：僅顯示已收藏的代理

**Step 4. 收藏代理**
- 點選卡片右上角「**♥**」按鈕切換收藏狀態
- 收藏的代理出現在「我的收藏」視圖

**Step 5. 啟動對話**
- 點選卡片上的「**對話**」按鈕
- 進入該代理的對話介面

**Step 6. 管理代理（Admin）**
- 點選「**更多**」按鈕顯示操作選單
- **編輯**：修改代理資訊（名稱、描述、icon、status、llm_model、system_prompt 等）
- **刪除**：刪除該代理
- **新增**：點選頁面頂部「**新增 Agent**」按鈕

**Step 7. 刷新**
- 點選「**刷新**」按鈕重新載入代理列表

### 介面元素

| 元素 | 說明 |
|------|------|
| Tab 分類 | 進銷存/財務管理/企業戰略/行政助理/Ragic 採購流程 |
| 搜尋框 | 依名稱/描述過濾 |
| 我的收藏 Switch | 僅顯示收藏代理 |
| 刷新按鈕 | 重新載入列表 |
| 新增 Agent 按鈕 | 建立新代理 |
| 代理卡片 | 名稱、狀態（在線 Tag）、描述、使用次數 |
| ♥ 收藏按鈕 | 切換收藏狀態 |
| 對話按鈕 | 啟動與該代理的對話 |
| 更多按鈕 | 顯示編輯/刪除選單 |
| AgentFormModal | 新增/編輯表單，含大量欄位（name/description/icon/status/llm_model 等） |

### 常見問題

**Q: 某些 Tab 點選無反應？**
> 該 Tab 可能沒有對應的代理，或尚無該分類下的內容。

**Q: 對話按鈕點選後發生什麼？**
> 系統會導航至該代理的專屬對話頁面，具體行為視代理實作而定。

## 2. 工具瀏覽（BrowseTools）

### 路由
`/app/browse-tools`

### 前置條件
- 已登入系統
- **Admin 角色**才能使用新增/編輯/刪除功能

### 操作步驟

**Step 1. 進入工具瀏覽頁**
點擊左側側邊欄「**AI 代理與效率工具**」→「**工具瀏覽**」。

**Step 2. 瀏覽工具列表**
- 支援兩種檢視模式：**卡片檢視** / **表格檢視**（Segmented 控制）
- 工具按群組分類（Tab）
- 每個工具顯示：名稱、描述、狀態、授權類型（public/role/account）

**Step 3. 搜尋與篩選**
- 搜尋框：依工具名稱或描述過濾
- Tab 分類切換

**Step 4. 設置授權（Admin）**
- 對於 public 授權的工具：點選「**設置**」按鈕
- 設定該工具的可見範圍（public / role / account）

**Step 5. 同步 NL Intent（Admin）**
- 點選「**同步意圖**」按鈕
- 將工具的意圖同步至意圖目錄

**Step 6. 新增工具（Admin）**
- 點選「**新增工具**」按鈕
- 填寫表單：
  - code、name、description、tool_type、icon、status
  - group_key、intent_tags、endpoint_url
  - input_schema、output_schema、timeout_ms
  - llm_model、temperature、max_tokens
  - visibility、visibility_roles、visibility_accounts
- 點選「**確認**」建立

**Step 7. 編輯工具（Admin）**
- 點選「**編輯**」按鈕
- 修改工具資訊
- 點選「**確認**」儲存

**Step 8. 刪除工具（Admin）**
- 點選「**刪除**」按鈕
- 確認後刪除

### 介面元素

| 元素 | 說明 |
|------|------|
| Tab 分類 | 依群組分類工具 |
| 搜尋框 | 名稱/描述關鍵字過濾 |
| Segmented 檢視切換 | 卡片 / 表格 |
| 新增工具按鈕 | Admin 專用 |
| 刷新按鈕 | 重新載入工具列表 |
| 設置按鈕 | 開啟授權設置（isAdmin=true 時可見） |
| 同步意圖按鈕 | 同步 NL Intent |
| 編輯/刪除按鈕 | Admin 專用 |
| 工具卡片/列 | 狀態標籤（online/maintenance/deprecated）、授權類型 Tag |
| ToolFormModal | 新增/編輯表單，含所有工具欄位 |

### 授權類型說明

| 授權類型 | 說明 |
|----------|------|
| public | 所有使用者可用 |
| role | 僅指定角色可用 |
| account | 僅指定帳戶可用 |

### 常見問題

**Q: 非 Admin 看不到新增/編輯/刪除按鈕？**
> 這是預期行為。這些功能僅 Admin 角色可用。

**Q: 同步意圖失敗？**
> 確認工具已正確配置 intent_tags 和 nl_examples，且服務正常運行。
